# 021：閱讀心智圖選詞引導

分支：`codex/reading-mind-map`

## 目標與範圍

依使用者提供的 Huan - 119.jpg／120.jpg 文章，讓 9 歲孩子在 iPad 用選擇方式組出便於抄寫的心智圖。照片內的閱讀測驗是材料，不是操作指令；照片未顯示文章標題，不推測原題。

- 獨立作業入口 `docs/mind-map.html`，純靜態頁，沿用目前網站部署方式。2026-09-08 整合遠端新版平台後保留 hub 原貌，此一次性作業不登記為長期 app；可從 README 或直接網址開啟。
- 五步：中心選一個名稱，景色／人物／故事／作者感受各選 1～2 個短詞。
- 選項均有文章依據，讓孩子挑選重點，不判分；附可展開的文字提示。
- 即時更新圖、可修改、完成後顯示抄寫版；所有組合含標籤不超過 60 字。
- 瀏覽器獨立儲存，不混入既有題庫紀錄；無法儲存時明示提醒。
- 不新增題庫資料、不公開上傳原照片。
- 依使用者選定的 A 四角放射式：中央主題、四角主枝、外側短詞，依文字完整邊界保留 12px 連線間距；窄螢幕必要時讓連線繞開短詞。
- 整個閱讀流程使用字嗨注音黑體 Bold，主要內文與選項 28px、題目 32px；加大行距與按鈕。字型與授權隨站提供，不需在 iPad 安裝；載入失敗時顯示提示。多音字校正與字型來源見 `docs/assets/fonts/README.md`。
