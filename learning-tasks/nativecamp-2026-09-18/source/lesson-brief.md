# 2026-09-18：Food, stories and sharing

Zeus，19:30（Asia/Taipei），Oxford Discover 1 Unit 10，第 96–100 頁。5 個概念，每概念 Try／Say 各 3 題，共 30 題、60 段問題／答案語音。題目唯一真相源為 [lesson-source.json](lesson-source.json)，製作標準依 [SOP](../../nativecamp-review-pilot/lesson-sop.md)。

本包目標是把課堂的分類、閱讀順序及簡短回答轉成完整句；不再用純單字選擇。每個 Change 都改變句子任務或需判斷的條件，而非只換一個食物名稱。三題並非必做：Try 先跨概念完成 Build、Change，前兩題獨立成功就略過 Fix；Say 每回一概念。孩子實際難度與時間未測。

## 概念、六題及家長判準

### `food-or-object`：What can we eat?

目標是按卡片區分食物與非食物，用肯定或否定完整句。Try 2 由食物轉為非食物，需要增加 do not；Say 3 合併兩項對比，不只逐題重複名詞。cue 提供 We，不供應 eat／do not。

| 題目 | 示範答案與成功判準 |
| --- | --- |
| Try 1 Build | `We eat carrots.`；字卡留下 not。 |
| Try 2 Change | `We do not eat stones.`；由肯定改成否定，留下 are。 |
| Try 3 Fix | 把 `We are not eat pots.` 的 are 改成 do，其他字不變。 |
| Say 1 | `We eat potatoes.`；We can eat potatoes 也可。 |
| Say 2 | `We do not eat pots.`；don't／cannot 皆可，不只說 pots 或 No。 |
| Say 3 | `We eat onions, but we do not eat stones.`；需同時表達兩項，don't／can…cannot 也可。 |

### `have-any-food`：Ask about food

目標是用 have any 詢問食物，並用完整句回應有／沒有。Try 2 從自己的否定陳述改為向另一組提問，需要主詞及問句語序轉換。Say 的判準依卡片，答案不要求逐字相同。

| 題目 | 示範答案與成功判準 |
| --- | --- |
| Try 1 Build | `We do not have any onions.`；小組 onions 為 0，留下 has。 |
| Try 2 Change | `Do you have any onions?`；改為詢問 Lee 的小組，留下 has。 |
| Try 3 Fix | 把 `Do you has any carrots?` 的 has 改成 have。 |
| Say 1 | `Do you have any food?`；Have you got any food 也可；不是替 Kim 猜有沒有。 |
| Say 2 | `We do not have any potatoes.`；don't／We have no potatoes 皆可。 |
| Say 3 | `We have three sausages.`；We have some sausages 也可；不能只有 Yes 或 three。 |

### `story-parts`：Beginning, middle and end

目標是從三步卡找對事件並以完整句說明段落。Try 2 同時改成兩位角色及故事結尾，需要選不同事件並使用複數動詞。卡片中的 1／2／3 是故事順序，不是原課教材的圖片編號。

| 題目 | 示範答案與成功判準 |
| --- | --- |
| Try 1 Build | `The girl draws a tree in the middle.`；卡片中間是畫樹，留下 draw。 |
| Try 2 Change | `The girls show the picture at the end.`；兩位女孩、結尾展示，留下 shows。 |
| Try 3 Fix | 把 `The boy draw a house at the beginning.` 的 draw 改成 draws。 |
| Say 1 | `They get a pot at the beginning.`；可把 At the beginning 放前面或以 The children 作主詞。 |
| Say 2 | `The boy draws a cat in the middle.`；He 或 In the middle 置前亦可。 |
| Say 3 | `They eat soup at the end.`；The children 或 At the end 置前亦可。 |

Say 接受自然前後順序；Try instruction 指定句首與結尾，使字卡有唯一目標語序。只說事件動詞或 beginning／middle／end 不算完整回答。

### `food-totals`：How many altogether?

目標是分清在算哪一群物件，表達完整數量句，並能反向提出數量問題。算式很短，數學不是本包難度來源；Try 2 改成提問，Say 3 需要排除鍋外物件。

| 題目 | 示範答案與成功判準 |
| --- | --- |
| Try 1 Build | 3＋5：`They have eight potatoes.`，留下 potato。 |
| Try 2 Change | `How many potatoes do they have?`；由回答改為提問，留下 does。 |
| Try 3 Fix | 4＋3：把 `They have seven carrot.` 的 carrot 改成 carrots。 |
| Say 1 | 2＋5：`They have seven sausages.`；可加 altogether 或用兩位角色名字。 |
| Say 2 | 向 Mia 問 `How many onions do you have?`；have you got／are in your basket 亦可。 |
| Say 3 | 鍋內 3＋2、碗裡另有 4：`There are five carrots in the pot.`；The pot has five carrots 等自然完整句亦可，不能把碗內數量算進來。 |

### `sharing-reasons`：Tell us why

目標是把明示的狀態與原因連接成 because 完整句。Try 2 由 no food／hungry 改成 food／not hungry，需要把否定放到主句；不是只換名詞。場景為故事條件，不以孩子現實飢餓或是否願意分享評分。

| 題目 | 示範答案與成功判準 |
| --- | --- |
| Try 1 Build | `We are hungry because we have no food.`；留下 not。 |
| Try 2 Change | `We are not hungry because we have food.`；留下 no。 |
| Try 3 Fix | 把 `They are not hungry because they has soup.` 的 has 改成 have。 |
| Say 1 | `He is hungry because he has no food.`；doesn't have any food 或 The boy 亦可。 |
| Say 2 | `They are not hungry because they have soup.`；aren't 或 The children 亦可。 |
| Say 3 | `Everyone has soup because they share.`；They all have soup 或 the children share 亦可。 |

每個原因都必須符合卡片；只回答 Because… 片語不算本題完整句。家長可接受同義而事實一致的自然英文，不機械要求示範逐字相同。
