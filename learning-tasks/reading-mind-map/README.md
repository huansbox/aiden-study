# 閱讀心智圖選詞引導

- 日期：2026-09-08；對象：9 歲孩子，成人可陪讀。
- 成品：已發布，真機試用待回饋。見 [任務紀錄](../../issues/021-reading-mind-map.md)。
- [開啟網頁](https://huansbox.github.io/aiden-study/mind-map.html)

依司馬光與〈客中初夏〉的文章，用五步選擇題組出中央主題、四角分支的心智圖。孩子挑自己想記住的重點，不計分；最後用短詞抄到作業本。

## 使用

iPad 橫向開啟，依序選中心、景色、人物、故事、作者感受；想不起來時展開提示。完成後可修改、截圖或列印。Safari「分享 → 加入主畫面」可作為網頁 App 開啟。首次使用需連網，沒有離線功能；進度只存當前瀏覽器，不同步。

## 可沿用的設計

- 每次處理一個分支，每組選 1～2 個短詞，選項均有文章依據。
- 使用字嗨注音黑體 Bold，多音字僅在顯示時校正，不污染存檔。
- 連線依文字邊界量測，保留注音空間。
- 橫向左右分欄，完成圖依可用高度調整，保留手動縮放。
