# 第二輪跨出版社自然原卷：五堵翰林地表候選

檢查日期：2026-09-27。**本輪新增 1 份官方題目原卷（2 頁），確證翰林；不是四上第一次段考卷。**五堵卷卷首為「113 學年度第二學期期末評量四年級自然科」，用來比較相同地表概念的題型，不能代表桃子腳 115 學年度四上第一次評量範圍或其命題。沒有新增 App 活動，也沒有取得本卷官方答案。

原卷出自[基隆市五堵國小校方檔案](https://oldwdps.kl.edu.tw/docs/file/314/113%E5%9B%9B%E4%B8%8B%E6%9C%9F%E6%9C%AB%E8%87%AA%E7%84%B6.pdf)。[同校 113 學年度教科書選用表](https://king.kl.edu.tw/course/file/164/%E7%AC%AC%E4%B8%80%E6%AC%A1%E6%9C%83%E8%AD%B0.pdf)的 PDF 第 8 頁「自然 × 四年級」格為翰林；已保存該頁影像供逐格覆核。原卷 307,615 bytes、PDF magic `%PDF-`、SHA-256 `D2F3DCDA3E1652CE9C4AA3A626BB55ADD428DAF1310CF2CF3D492C8991BB9027`，2 頁 A3。兩頁均已渲染並視覺檢查卷首、題號、共用代號與必要圖示。原件及驗證用圖檔存於被 Git 忽略的 `source/papers/`、`source/private/round2-cross/`，詳細路徑和版本表雜湊見 [manifest](round2-cross-publisher-manifest.json)。
