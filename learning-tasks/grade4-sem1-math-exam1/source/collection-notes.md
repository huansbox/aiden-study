## 來源與下載方法

### tcool

- 現行清單不再提供固定 `/d/q/<id>.pdf`；題目與官方答案按鈕使用 `data-exam-id`，點擊後呼叫 `api-exam.php` 的 `download_url` 動作取得短效簽發 URL。
- 清單查詢本身可無介面完成；直接下載端點受 Cloudflare 保護，匿名額度用完後回傳 `TRIAL_LOGIN_REQUIRED`，要求登入。本輪未登入、未繞過限制。
- 已取得的 tcool PDF 是在簽發 URL 正常通過 Cloudflare 後開於 Chrome PDF 檢視器，再從 Chrome 暫存檔複製到任務資料夾。這條路徑雖取得完整 PDF，但點檢視器「下載」會依使用者 Chrome 設定觸發原生「另存新檔」視窗，不適合自動化批次。

### 瀏覽器干擾與正確修正

- 干擾來源：點擊 tcool PDF 檢視器的「下載」按鈕；使用者的 Chrome 設為每次詢問儲存位置，因此累積原生「另存新檔」視窗。Google Drive UI 的「下載」也顯示「無法下載檔案」，不再重試。
- 現有瀏覽器控制只能操作網頁分頁，不能安全鎖定並取消原生檔案對話框；沒有關閉 Chrome、其他分頁或修改全域下載設定。統籌者已請家長自行取消既有視窗。
- 後續禁止再點 Chrome 下載按鈕。只讀來源 metadata 可用非前景工具；實體檔案必須交給無介面下載器直接寫入明確工作路徑。

## 失敗與未取得

- tcool 批次無介面 API：匿名額度觸發 `TRIAL_LOGIN_REQUIRED`；沒有使用登入、付費或繞過手段。
- tcool 明義 114、建德 114：在匿名限制後沒有取得檔案。其餘未下載候選是「未嘗試」，不能列作下載成功或下載失敗。
- 安和 Drive UI 下載：顯示「無法下載檔案」；已改用公開 `drive.usercontent` 無介面直連成功，因此安和 112 最終不是 blocker。
- 民權 114：只有題目卷；tcool 顯示的是站內產生答案，不是官方答案，本輪不採用。
