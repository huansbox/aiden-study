### 三種適用分類與整卷用法

分類相對於上述「115 第一次考試暫定基準」，不是版權／答案品質標籤；來源、答案狀態仍需另記。

| 分類 | 判準 | 必填記錄與例子 |
| --- | --- | --- |
| **可用（依暫定範圍）** | 所需概念皆落在 M1–M4、M5a，圖文可辨識、沒有依賴未教概念 | 記題號、概念標籤、115 單元；例如 111 的四位÷二位題可用，111 後半學期的公里換算也可能可用 |
| **部分可用** | 同份卷／同大題混有符合與超出範圍題；可以明確拆出子題 | 明列保留與移出題號及理由。例：保留角度測量、移出三角形分類；保留二位乘數、移出三位乘數；公里加減另掛待確認 |
| **暫不納入／待確認** | 明確是今年後續概念，或考試週邊界、版本／題圖不明，尚不能判定 | 加註原因：`後續-U6`、`後續-U7/U8/U9/U10`、`位數超界`、`範圍待確認-M5b`、`題圖待核`。已知後續概念不是內容無效，保留供相應進度 |

- 一份卷只有在逐題均通過時才能列「可用」。有任一需要拆出的題，就列「部分可用」，不能以「同為康軒」整卷沿用。
- 已核整卷都在範圍外者列「暫不納入／已知後續」，不是「待查」；範圍或圖文真不明時才列「待確認」。
- `可用` 不代表足夠覆蓋本次目標。111–112 期中卷可能缺公里；114 翰林期中卷可能缺康軒本次需要的完整除法。需按 M1–M5a 補缺，不必為保留原卷順序犧牲今年進度。
- 題組前後相依時，不能只切下最後一小題；須保留足夠條件。若後續改寫題目，另標改編並重新驗算。只依題目關鍵詞自動判定不可靠。
- 位數界線看的是「作答必須使用的計算方法」。例如 12×345 的生活題，若允許寫成 345×12，就可能使用本次已列的三位×二位方法；若題目強制以原順序練三位乘數直式，則另核。不要因出現一個三位數就移出；234×123 這種兩個因數都三位的直式題，才是明確超出 M2 的例子。

來源：[校方 114 翰林四年級計畫][S9]，首頁明列 114、四年級；第三至十二週有具體活動，並非只讀檔名。

| 翰林來源位置 | 內容 | 映射至 115 康軒與本次處理 |
| --- | --- | --- |
| U1，W1–2 | 一億內數、位值、大小與加減 | 對應 U1；逐題核可用 |
| U2，W3–4 | 乘以一／二位數，**另含乘以三位數**、乘法算式規律 | 部分對應 U2；M2 位數範圍可用，三位乘數移出，額外規律題看依賴的概念 |
| U3，W5–6 | 量角器、測量畫角、旋轉、合角分角 | 對應 U3；核心概念相符，但仍核圖與解法 |
| U4，W7–8 | 真／假／帶分數、互換、大小、**分數數線** | 真／假／帶分數等對應康軒 U9 的相關內容，推定本次不納入；數線須另核今年教材位置，不把整個翰林 U4 當康軒 U9 完全等同 |
| U5，W9 | 公里、換算比較、二階單位加減 | 換算比較對應 M5a；加減對應 M5b，待確認；公里題內若另要求除法也要核位數與解題條件 |
| U6，W11–12 | 除以一／二位數，**另含三位數除數** | 前段可補康軒 U4（即使來自翰林期中後題）；三位除數移出本次 |
| U7，W13–14 | 三角形分類、畫三角形、全等 | 對應康軒 U6，推定本次不納入、保留後用 |

這是 114 翰林的直接證據，**不將其不經查證地套成所有年度翰林內容**。112 翰林卷也用 M1–M5 逐題核查；本稿未完成 112 翰林整冊版本校勘，不預先宣稱它與 114 完全一致。

### 桃子腳 110 南一：舊卷仍有可用概念

來源：[110 南一四年級數學計畫][S10]。公開 Drive 預覽第 1–2 頁明列年度、年級、全冊架構；第 4 頁開始的週表「使用教材」列南一。檔案是舊式 DOC，connector 的文字回傳為空，並不表示原稿空白；本次已直接取得原檔並核對公開預覽的標題／架構。

| 南一來源位置 | 115 映射與處理 |
| --- | --- |
| U1 一億以內的數 | 對應 M1a 等相關內容；逐題查實際數值，不能把其舊能力指標中的「億、兆」當作整卷超界的證明 |
| U2 乘法、U3 角度、U4 除法 | 對應康軒 U2／U3／U4 的部分內容，按 M2–M4 的位數、角度與工具篩選；本稿不宣稱逐題深度一致 |
| U5 三角形 | 今年仍有，移至康軒 U6；推定本次不納入 |
| U6 分數、U8 整數四則、U9 小數 | 分別對應今年 U9／U8／U7 的相關內容，推定本次不納入；分數數線等額外內容另核 |
| U7 容量和重量的計算 | 115 四上十單元中沒有這個同名單元；不是公里換算，不能套 M5；若需後用再查今年相應冊次 |
| U10 長度 | 文件學期目標明列公里與公尺換算、相關計算；可尋找符合 M5a 的題補缺，M5b 仍待確認 |

110 文件使用 N-2-02、4-n-01 等舊能力指標，115 使用 N-4-1 等學習內容代碼；**本次以實際概念判斷，不訂「110 全卷無效」的年度門檻**。舊文件的題圖、數值與學習要求仍須在卷面核對。

## 缺口與下一步（不阻擋現有題目蒐集）

1. 取得學校／任課教師明確的 115 第一次數學範圍（單元、小節或課本／習作頁碼）後，更新 M5b 及 U6 邊界；此前維持「推定／待確認」標示，不要求家長現在回答。
2. 實際 113 桃子腳卷由蒐集工作核對題號與內容，以解開文件年級、順序矛盾對該卷的影響。這不影響先按概念挑題。
3. 比較目前核到「教學計畫的核心概念」，未完成各年課本逐頁、教師手冊與出版社版次／ISBN 的校勘。對超出表列位數、工具或概念的題目保持待確認，不推測今年已教。
4. 不把其他學校的課程週次當桃子腳正式進度；115 範圍優先採桃子腳 [S3][S3]，康軒 [S2][S2]交叉核對。
