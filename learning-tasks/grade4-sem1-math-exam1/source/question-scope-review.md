# 五份歷屆卷逐題範圍審查

## 結論

五份卷都只能「部分使用」，沒有任何一份可整卷直接沿用，也沒有整份必須暫時排除的卷。共核對 **216 個作答單位**：`core_provisional` 179、`hold_scope` 11、`later_scope` 26、`needs_review` 0。

這些狀態以 `curriculum-comparison.md` 的暫定工作基準判定：M1–M4、M5a 列核心；M5b 公里加減列待確認；U6 三角形列後續。**115 第一次段考的正式單元／頁碼範圍仍未公布**，所以 `core_provisional` 不能改寫成「學校已公告會考」。

## 統計口徑

本次以「最小可分開作答的作答格」計數，不以印刷題號或配分題數計數：

- 一個選項、是非判斷、連線列、作圖或未分小題的應用題結果，各算一個作答單位。
- 公里與公尺印成兩格時算兩個；商與餘數印成兩格時也算兩個；另有驗算框時再算一個。
- 同一題組的多格即使分開計數，仍記錄 `dependency`；後續抽題不能只留下失去表格、圖或前題資料的一格。
- JSON 採群組壓縮：`review_groups[].ids` 中每個 ID 都繼承同群組的頁碼、概念、115 單元、狀態與理由。ID 格式固定為 `paper_id-大題-題號/作答格`。

## 核心覆蓋與缺口

目前核心池已涵蓋：

- M1：一億以內讀寫、位值、化聚、大小與大數加減。
- M2：四位數乘一位數、三／四位數乘二位數、整十／整百倍及生活情境。
- M3：量角器、畫角、角分類、平角／周角、旋轉與角的合成分解。
- M4：一／二位數除數、估商、商位數、餘數、驗算與進一／捨去情境。
- M5a：有 **20 個標記單位**，其中 **14 個直接使用公里**，分布在桃子腳 113、安和 114、民權 114 三卷；包含公里量感、公里↔公尺、公里↔公分與大小比較。

因此，**M5a 的公里換算／比較在這五卷合併後不算不足**。真正的結構性缺口是：桃子腳 111、安和 112 完全沒有 M5a，若只挑這兩份舊順序期中卷會漏掉 U5；此外，合併池的公里題集中在三份較新卷，後續組卷仍應避免讓單一卷來源占比過高。

仍需保留的邊界：

1. M5b 共 11 個作答單位，只能當候選備用，等正式範圍確認後整批放行或移出。
2. U6／範圍外共 26 個單位：25 個是三角形相關後續內容，1 個是實際數值大於一億的九位數讀法；都不是因舊年度或單元排序而排除。
3. `needs_review` 為 0，代表卷面足以分類，不代表校方已確認考試範圍。

## 待決策事項

正式範圍公告後只需處理兩個門：

1. 是否包含 M5b 公里／公尺二階單位加減與路線題；若不含，11 個 `hold_scope` 維持不用。
2. 是否意外提前包含 U6；若沒有，25 個三角形單位維持後用。

逐作答單位的穩定 ID、PDF 頁碼、概念標籤、115 單元、狀態、理由與題組依賴，見 `question-scope-review.json`。
