## 檔案索引

- `source/manifest.json`：逐卷來源、身分、下載狀態、PDF 驗證、SHA256 與範圍狀態。
- `source/collection-notes.md`：23 份候選清單、取得限制、失敗與後續安全收集方法。
- `source/curriculum-comparison.md`：115 暫定範圍、跨年度單元映射與逐概念邊界。
- `source/question-scope-review.json`：五份卷逐作答單位的穩定 ID、頁碼、概念、狀態、理由與依賴。
- `source/question-scope-review.md`：逐卷分類、數量統計、覆蓋與待決策摘要。
- `source/papers/`：本機原卷；由局部 `.gitignore` 排除，不提交、不公開再散布。

## 再製方式

1. 先讀 `source/manifest.json` 與 `source/collection-notes.md`，不要只看檔名判斷版本或範圍。
2. 原卷優先從學校官方公開題庫的穩定檔案 URL 以無介面下載器寫入 `source/papers/`。
3. 每次取得後檢查 `%PDF-` 魔術字、頁數、全頁渲染可讀性與 SHA256；答案另核對是否為學校官方、第三方或 AI。
4. tcool 的匿名下載會要求登入，且 Chrome PDF 檢視器下載會觸發原生「另存新檔」視窗；不要用該按鈕批次收集。找不到公開無介面來源時，記錄待取得，不繞過限制。

本任務目前不轉寫題目、不生成答案、不加入網站題庫，也不處理自然或社會考卷。
