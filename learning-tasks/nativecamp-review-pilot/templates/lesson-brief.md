# Native Camp 單堂複習設計單：〔lesson ID〕

這是製作模板，不是可直接載入的題包。複製到該堂來源目錄後填寫；〔〕是待填欄位，無資料就明示「未提供／未確定／未測」，不得帶著占位內容發布。規則以[製作SOP](../lesson-sop.md)為準；複製後修正此相對連結。

## 6. 驗收與交付

勾選必須有實際證據；無關項註明不適用。

- [ ] 概念選擇有來源，未把老師提示、跟讀或ASR誤標當成孩子獨立表現。
- [ ] 每概念各3題Try／Say；變體不同，答案、圖像、數量與語音一致。
- [ ] Try答案封閉；排列合理答案完整；Say替代句與家長判準明確。
- [ ] 孩子畫面全英文、短句、無emoji；句型cue只在作答區出現一份且清楚可讀。
- [ ] 問題音檔不洩答案；自動播放、重聽、揭曉／回饋、切題／背景取消正常。
- [ ] 前兩題獨立成功／錯誤／協助、隔天確認與首次紀錄的規則沿用SOP。
- [ ] Preview不寫學習紀錄；正式資料未被測試或重置。
- [ ] 新課來源可重建；未覆寫舊課、音檔、ID或舊進度；入口一致。
- [ ] 檔案解碼、內容核對、相關tests與獨立review完成；私人檔案確認ignored。
- [ ] 若本次含發布，記錄CI、Pages、必要的Worker／KV及正式讀取結果。
- [ ] 本堂README、任務索引、追蹤工作與交付入口已更新。
