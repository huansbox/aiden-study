# 音訊與複習內容核對

日期：2026-09-16。適用範圍：這一份已下載的課程音檔，以及已抽查的五段內容。

## 核對方式

使用 `faster-whisper 1.2.1`、`small.en` 模型、CPU int8 在本機轉錄。第一次將三個抽樣片段交由預設音訊解碼合併聲道，發現中後段大量學員回答沒有出現在結果中。檢查左右聲道波形後，改成每個聲道分別轉錄，並追加閱讀主題與句型遷移兩段，總共 **385 秒（約全課 25.6%）**。

模型下載來自 Hugging Face；錄音只在本機處理，未上傳轉錄服務。沒有以原網站逐字稿作為模型 prompt，避免用預期答案影響本次獨立核對。

### 重要結果

1. 五段抽樣皆得到老師端與學員端的對話內容。依問答上下文推定，本檔 channel 0（左）主要為老師端，channel 1（右）主要為學員端。這是本檔的抽樣判讀，不是通用的 Native Camp 聲道規格，也不是聲紋辨識；學員端可能包含家長聲音。
2. 兩聲道不是相同的複本，抽樣中的相關係數接近零。老師端平均能量較大；混合轉錄遺漏學員端內容，因此本任務採分聲道核對。
3. 回放含有學員端回答，不是只有老師聲音。但只驗證抽樣，不能宣稱全程零缺錄。
4. 語音模型仍會把短詞、名字與不完整句辨識錯誤，並把相隔的發話合成一個很長的 segment。因此只用寬鬆時間範圍供回查，不宣稱逐字起訖或停頓長度已精準對齊。
5. 沒有人工聽辨或直接音訊模型的發音評估；轉錄成功與否不能當作發音分數。

## 教材核對

實際開啟課堂聊天連結，確認為 Oxford Discover 1 Student Book。翻頁器頁碼比印刷頁碼多 2：viewer 88 對應教材第 86-87 頁；viewer 90 對應第 88-89 頁。

- 第 86-87 頁：數字、球與球員數量，以及數字的用途。
- 第 88 頁：數學相關詞彙、加法、奇偶數。
- 第 89 頁：由標題預測文章內容；例子涉及人數、樹與衣物。

成品使用原創的五棵樹、玩具標題與裝不下的玩具箱；不複製教材頁，也不要求家長額外開啟教材才能陪練。

## 成品驗收

- 孩子版一頁、家長版一頁；三個重點與一個暖身題，建議 5-10 分鐘，實際時間待孩子試用。
- 五棵樹的圖與家長答案一致；9 為奇數。主題預測允許合理答案；玩具題允許多種正確句型。
- 家長提示與完整答案不放在孩子版。家長記錄獨立回答、提示後回答或示範後跟讀，不將跟讀當成已學會。
- PDF 已渲染並視覺檢查：中文字可讀，沒有重疊、裁切、缺字或意外多頁。
- 音檔、片段、原網站節錄與原始 ASR 結果只留在忽略目錄；追蹤檔案不含簽章網址。

## 檔案與再製

- `check_audio.py`：驗證原始錄音 SHA256、抽取五段 WAV、執行本機 ASR；`--separate-channels` 為本次採用方式，`--offline` 限用已快取模型。
- `private/local-audio-check.json`：初次混合模式結果，保留作為選擇分聲道的依據。
- `private/local-channel-check.json`：五段分聲道結果，包含原始 segment 與 word timestamps；精確時間尚未做強制對齊驗證。
- `private/website-excerpts.json`：少量原網站節錄，保留原始標籤與文字。
- `audio-validation.json`：不含逐字內容的抽樣驗證摘要。
- `review-content.json` 與 `build_review.py`：可編輯題目與 PDF 重建來源。
