# Native Camp 回放複習方案

日期：2026-09-16。工作分支：`codex/nativecamp-audio-review`。

## 結論與本次範圍

**目前這堂課的回放可下載。**已透過 Chrome 原生媒體下載選項取得 WebM，並完成整份解碼驗證。後續可保留原始音檔，結合網站逐字稿與教材做複習分析，不需要先錄製一次電腦播放聲音。

本次交付為工作分支、下載實測、檔案驗證與方案。不進行雲端轉錄、發音評分、出題、網站發布或批次擷取其他課程。這份方案中的後續階段是建議，尚未實作。

## 第一階段：取得與驗證音檔（已完成）

### 已驗證事實

- 樣本課程：2026-09-15 19:30；網站顯示回放長度 25:04。
- 課程播放器在教材 iframe 的 `#pop-player-audio` 中提供帶時效簽章的 HTTPS WebM 來源。
- 網站原生逐字稿可讀，帶有時間與師生標籤，但已有說話者標錯與疑似辨識錯字的例子。
- 下載檔案：`../assets/audio/2026-09-15-1930-lesson.webm`。
- 大小：11,152,631 bytes；長度：1504.625 秒；一條 Opus 音軌；48,000 Hz；雙聲道。
- `ffmpeg` 以錯誤即停止方式完整解碼，exit code 為 0，沒有錯誤輸出。
- 音檔與私人逐字稿的預定目錄已由局部 `.gitignore` 排除；版控不包含音檔或簽章網址。

### 實際可重現的下載路徑

1. 在使用者已登入且授權的 Chrome 中，開啟指定課程複習頁；確認課程日期、時間與回放長度。
2. 從目前頁面的教材 iframe 讀取播放器音訊元素；每次重新取得當下有效的來源，不重用過期網址。
3. 本次 `downloadMedia()` 開啟 Chrome 原生媒體頁，並未直接把檔案保存。若開始自動播放，先暫停。
4. 在該媒體頁的「顯示更多媒體控制項」選單點「下載」，等待瀏覽器的 download 事件，再確認對應的完整檔案已落地。事件本身不等於下載驗證完成。
5. 將下載檔複製至 task 的 `assets/audio/`，用穩定檔名保存；若目標已存在，先核對檔案，不直接覆寫。
6. 檢查格式、長度、檔案大小、SHA256 與完整解碼。最後將 Chrome 返回原課程及逐字稿檢視。

本次 Chrome 內部下載紀錄頁被瀏覽器工具的 URL policy 封鎖；未繞過該限制。下載透過媒體頁的正常「下載」選項完成，再直接檢查產出的本機檔案。`pageAssets` 在本次原生媒體頁回傳空清單，不能作為這個來源的匯出方式。

### 本機驗證指令

在 repo 根目錄執行（需已有 `ffprobe` 與 `ffmpeg`）：

```powershell
ffprobe -v error -show_entries 'format=format_name,duration,size,bit_rate:stream=index,codec_name,codec_type,sample_rate,channels,channel_layout' -of json 'learning-tasks/nativecamp-review-pilot/assets/audio/2026-09-15-1930-lesson.webm'
ffmpeg -hide_banner -nostdin -v error -xerror -i 'learning-tasks/nativecamp-review-pilot/assets/audio/2026-09-15-1930-lesson.webm' -map 0:a:0 -f null -
Get-FileHash -Algorithm SHA256 -LiteralPath 'learning-tasks/nativecamp-review-pilot/assets/audio/2026-09-15-1930-lesson.webm'
```

重新下載同一堂課若取得不同版本，需重新驗證；不能假定 SHA256 必須永遠相同。

## 第二階段：確認聲音內容與分析方式（建議下一步）

先取開頭問答、中段問答與約 21 分鐘的朗讀片段做小範圍驗證，確認兩位說話者是否皆可聽見、音訊和網站逐字稿時間是否對得上。**一條雙聲道音軌不代表兩個聲道分別對應師生；完整解碼也不證明內容完整。**

音訊分析方式依目的選擇：

| 目的 | 建議作法 | 驗收條件 |
| --- | --- | --- |
| 整理單字、句型與課堂問答 | 先用網站逐字稿及教材，針對疑似錯字或說話者錯置核對短片段 | 每項重點可連回時間與上下文；不把老師的示範句當成孩子的錯誤 |
| 重建遺漏的對話 | 必要時評估本機轉錄或外部轉錄服務，先測短片段 | 可辨識老師、孩子及可能的家長；保留未聽清處，不擅自補字 |
| 檢查發音與語調 | 需要能直接處理音訊的分析工具，先確認其對兒童語音的適用程度 | 判斷引用實際音訊證據；不能只靠文字轉錄或辨識成功率打分 |

目前瀏覽器工具只提供網頁、媒體操作與下載，不把播放聲音直接傳給對話中的模型。下載成功不代表已完成音訊分析；本次也未設定或執行額外音訊模型。若選擇把課程音檔上傳外部服務，先確認具體服務、傳送範圍與使用者授權。

如需轉檔，保留原始 WebM，僅為分析工具不支援原格式或需截短片段時建立衍生檔；衍生音檔同樣放在忽略目錄。

## 第三階段：單堂複習試作（待第二階段驗證後）

建議先做約 5–10 分鐘、3 個重點的口說複習：一題熟悉內容暖身、一至兩題句型換情境使用、一題再次回答課堂問題。實際題數與形式依孩子實測調整，不先建題庫平台。

設計時區分「已能獨立回答」、「需提示才能完成」、「疑似辨識錯誤」三種情況。來源不確定的錯誤不列為孩子的弱點；老師的說法也需查核。每題保留來源時間、目標句型、可接受回答與提示方式，讓家長能核對。

通過條件：題目貼近本堂課、難度符合觀察到的表現、沒有把轉錄錯誤當成教學結論。先完成一堂試作，再決定是否值得做跨堂整理或自動化。

## 尚未驗證與停止條件

- 尚未聽取或用音訊模型檢查下載檔，因此師生聲音覆蓋、發音與語調均未確認。
- 目前只驗證一堂課；其他課程可能有多音軌、不同格式、缺錄或下載失敗。
- 網址過期時回到原課程取得新來源；下載若回傳登入頁、錯誤頁或解碼失敗，不將其當成音檔。
- 同類失敗若沒有新增證據，停止重試並記錄原因。來源取得確實不可行時，才另評估錄製系統聲音的備案。
