## 來源與保存

- `source/papers/`：取得的原題卷與官方答案 PDF，只留本機，不進 Git。
- `source/private/`：OCR、render、逐題核對與尚未公開的轉寫，只留本機，不進 Git。
- [校卷 manifest](source/school-manifest.json)：公開的來源 metadata；只記學校、學年度、學期、評量次別、題卷／答卷身分、來源 URL、頁數、SHA256，以及可查證的出版社證據。卷面或校方資料未證實的出版社標為未知。

原卷需由公開且允許取得的來源重新下載，逐頁確認題目、圖表與大題指示，核對 PDF 身分、頁數與 SHA256。遇登入或存取限制即記錄，不繞過限制。公開檔案不放原題、選項、答案、解說或原圖。完整 Git clone 不包含私用原件。
