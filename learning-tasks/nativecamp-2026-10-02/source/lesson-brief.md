## 目標與成功判準

| 概念 | 目標／混淆 | 成功判準 |
| --- | --- | --- |
| farm-places | Orchard 是水果樹生長的地方；cornfield 是玉米田。搭配 new／old。 | 地方與題卡作物一致；需要描述新舊時保留形容詞，使用完整句。Say 1 明確問地方類別，不問蘋果長在哪裡；描述為種果樹的地方亦是正確完整回答。 |
| building-descriptions | 單數 is、複數 are。 | 建築數量、描述及動詞一致；不能只回 tall／short／old。 |
| compare-characters | 不同的兩個事實用 but；同時談兩人用 have。 | 兩人的寵物／喜好對應正確；比較有完整主詞及動詞。Change 保留兩人，不只說其中一人有貓。 |
| where-they-live | One person lives／two people live，住家使用 in。 | 人物、住家大小與種類都符合卡片；街道口說 on／in 均可，不能把方言差異算錯。 |
| too-for-me | 從情境推定哪種特徵造成問題，並理解否定後問題不成立。 | noisy／boring／dangerous 與事實一致；not too noisy 正確表達可以睡覺。口說近義 loud／dull／unsafe 可接受。 |
| food-likes | 用完整肯定／否定句，I 搭配 don't，不用 doesn't。 | 所有指定食物喜好都正確，完整回答而非單字；don't 與 do not 等價。 |

Try 前兩題通常一個混淆字；farm-places Change 為兩個（old、cornfield），同時檢查地方與新舊。Fix 只有一個錯字、唯一正確替換；問題語音不先說出正確替換詞。hint 是孩子主動取得的協助，不能當成獨立成功。

所有 order 題指定句首；too 題另指定 for me 結尾；too-for-me Change 明示 Use too，排除同樣自然但未練目標結構的 not very noisy。重複字 token 的等價排列已全部加入 acceptedOrders。不讓交換重複 a／has／I／like 字卡造成假錯。住家 Say 1／3 的問題語音只讀 small apartment／big house 線索，再問 where；不先念完整 has a home in 示範。完整的 has a home in 回答仍是合理替代，不能藉縮窄 accepted 掩蓋語音洩漏。

Say 的 cue 是短句片段或句首加省略號；示範與合理替代皆符合事實及指定句型，不要求逐字照念。

## 每概念六題與答案

### Name the place

Change 從舊玉米田改成新的果樹農場，必須判斷地方及新舊，不能原封抄原句。Fix 僅 cornfield. → orchard.。

| Slot | Question ID | 示範答案 |
| --- | --- | --- |
| Try 1: build | farm-places-try-1 | This is an orchard. |
| Try 2: change | farm-places-try-2 | This is a new orchard. |
| Try 3: fix | farm-places-try-3 | The trees are in the orchard. |
| Say 1 | farm-places-say-1 | This is an orchard. |
| Say 2 | farm-places-say-2 | This is a new cornfield. |
| Say 3 | farm-places-say-3 | This is an old orchard. |

### Describe the buildings

Change 一棟變兩棟，hotel is 同時變 hotels are。Fix 僅 are → is。

| Try 2: change | building-descriptions-try-2 | The hotels are tall. |

### Compare two friends

Change 原先兩人寵物不同，改成兩人都有貓；兩個 has 子句改用複數主詞 have。Fix 僅 have → has。第三題回到短單句。

### Say what is a problem

Change 從噪音導致睡不著，變成安靜可睡，必須加入 not 否定原評價。Fix 僅 boring → dangerous，不改其他字。

Change 從喜歡 cheese 轉成不喜歡，加入否定而非只換食物。Fix 僅 doesn't → don't。第三題縮短為單一否定句。
