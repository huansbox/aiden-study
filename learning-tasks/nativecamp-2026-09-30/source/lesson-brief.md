以短文字卡練習名詞分類、邀請、mural 描述、顏料混合、主題預測及顏色比較。每題的核心是把已知線索說成完整句；不要求打字、自由聊天或看未提供的圖片。

課程：2026-09-30 19:30（Asia/Taipei），Edon。教材線索：Oxford Discover 1，第 34–38 頁，網站分為兩條音軌。共 6 個概念、36 題；每概念 3 題 Try 與 3 題 Say。Try 一輪約 12–18 題；Say 每回一個概念、2–3 題。實際耗時與孩子難度未測。

## 目標與成功判準

| 概念 | 目標 | 容易混淆 | 成功判準 |
| --- | --- | --- | --- |
| noun-groups | 完整說出名詞指人、地點或物品。 | person／place／thing；book is a thing 與 books are things。 | 分類符合一般課內分類，單複數一致；不能只說 person／place／thing。fireworks 在此當作 things。 |
| friendly-invitations | 用完整問句邀請，或在接受後提出一起活動的建議。 | Do you want to 問句與 Let's 建議；want to 後接原形。 | 邀請包含對方及指定活動；建議用 Let's 加活動。接受同義的 with me／together，不把 Sure 一字算本題的完整邀請。 |
| mural-descriptions | 用 mural(s) 作主詞，完整描述畫作中出現的物件。 | 一幅 shows，多幅 show；starfish／jellyfish 單複數同形。 | 數量、物件及 shows／show 與卡片一致；指定兩隻時須保留數量。不因會跟讀 mural 就認定詞義已掌握。 |
| mixing-paints | 依配色卡，以完整句說出混合兩種顏料的結果。 | mix／mixes；混合材料與產物；顏色先後可以交換。 | 主詞、兩種材料與結果符合卡片；可交換兩種顏料，也接受 make … by mixing 的口說改述。卡片是這組題目的顏料模型，不涵蓋各種真實顏料或光色。 |
| predicting-topics | 結合標題及開頭線索，以 I think 完整預測主題。 | orange 作顏色或水果；單字短答與完整預測。 | 保留預測語氣且主題受線索支持；同義主題均可。合理替代不是封閉白名單，但不能說出與線索衝突的主題。 |
| comparing-colors | 用完整句比較兩個已知顏色是否相同。 | same color／different colors；兩物需用 are。 | 判斷符合卡片且是完整句；說 both red／both gray 也已清楚表達相同。不能只回 same／different。 |

## 每概念六題與答案

Try 依序 Build／Change／Fix。所有排列題只有 1 個混淆字；正確字卡須全選。Start with 限定句首，其餘符合題意的自然排列均納入 acceptedOrders。相同文字的不同 token ID 全部列入等價交換；兩種顏料的先後均接受。

Say 的 instruction 只顯示短句首與省略號，例如 `A teacher …`；語音保留 Start with 引導。示範與 accepted 都遵守該句首。家長依內容及上述判準核對，並非逐字照念才算對。聲音、卡片與答案均以 JSON 最終版本為準。

### Name the noun group

## 提示、評級與難度

- 每個 Try 都有短英文 hint 與 explanation。hint 僅在孩子按 Show a hint 後出現；提示可協助選詞，但使用後記 With help，不算獨立成功。explanation 在作答回饋時才出現。
- 不預先念出排列結果；Fix 問題語音只提供情境與修正要求，不朗讀修好的完整句。活動名、物件名或顏色是情境已知事實，不是句型測驗的隱藏答案。
- 詞義支架放在短卡上，例如 wall painting 與配色表；所有 scene 都是 word-card，不稱為圖片，也不假裝孩子能看見卡上沒有的顏色。
- Say 先說再揭曉，依第一次表現評級；若家長已提供正確動詞或完整示範，應選 With help。前兩題獨立成功可收尾，有協助才補第三題。
- 題名、畫作、物件、角色及活動均為原創情境；不公開孩子個人偏好，不重刊課文。沒有自由聊天或自動發音評分。
- 新課沒有 tryRevision，不改舊題、舊課 ID 或既有進度；本回合完成不等於永久掌握。
