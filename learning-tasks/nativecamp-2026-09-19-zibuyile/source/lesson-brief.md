## 題目安排

### fruit-inside：What is inside?

Change 一顆桃子的 pit 改成兩顆桃子的 pits，同時改 These／have；只談卡片中已切開的水果，不做植物學分類推論。

| 題目 | 示範答案 |
| --- | --- |
| `fruit-inside-try-1` | This peach has a pit. |
| `fruit-inside-try-2` | These peaches have pits. |
| `fruit-inside-try-3` | This cucumber has seeds. |
| `fruit-inside-say-1` | This mango has a pit. |
| `fruit-inside-say-2` | These tomatoes have seeds. |
| `fruit-inside-say-3` | This avocado has a pit. |

### my-turn-your-turn：My turn, your turn

Build 和 Change 都是 I… and you… 雙分句；Change 保留同一批水果、換成另一人說話，兩人的數量必須交換。

| 題目 | 示範答案 |
| --- | --- |
| `my-turn-your-turn-try-1` | I have two mangoes and you have one mango. |
| `my-turn-your-turn-try-2` | I have one mango and you have two mangoes. |
| `my-turn-your-turn-try-3` | You have three peaches. |
| `my-turn-your-turn-say-1` | I have four oranges and you have two oranges. |
| `my-turn-your-turn-say-2` | I have two oranges and you have four oranges. |
| `my-turn-your-turn-say-3` | I have one avocado and you have three avocados. |

### fruit-total：How many together?

Build 說自己的三顆；Change 加入同伴兩顆，從 I 改 We 並推算五顆。Say 另有一題 plus／equals，避免把同一數學流程拆成多組。

| 題目 | 示範答案 |
| --- | --- |
| `fruit-total-try-1` | I have three tomatoes. |
| `fruit-total-try-2` | We have five tomatoes. |
| `fruit-total-try-3` | We have six peaches. |
| `fruit-total-say-1` | We have five mangoes. |
| `fruit-total-say-2` | Four plus three equals seven. |
| `fruit-total-say-3` | We have five cucumbers. |

### how-many：Ask about the total

Change 從共同的 we 改為直接問對方 you；Fix 修正可數水果的 much／many。口說依共同或對方所有，決定問句視角。

| 題目 | 示範答案 |
| --- | --- |
| `how-many-try-1` | How many oranges do we have? |
| `how-many-try-2` | How many oranges do you have? |
| `how-many-try-3` | How many mangoes do you have? |
| `how-many-say-1` | How many peaches do we have? |
| `how-many-say-2` | How many tomatoes do you have? |
| `how-many-say-3` | How many avocados do we have? |

## 作答與語音判準

- 所有故事人物、寵物、物品、數量與所有關係均為虛構。畫面／語音提供本題必要資訊，不要求孩子回想未提供的教材圖片或私人生活。
- 排列卡是單一單字，每題一個或兩個混淆字；instruction 明示剩餘卡數與必要句首，避免較短但語法成立的子句被誤認完整答案。自然字序仍須符合卡片中的人物、視角、事實與因果。
- Fix 只換一個詞，不同時藏兩個錯誤；第三題是同一能力的補強。
- Say 要說出本題指定資訊的完整句；縮寫、同義說法及自然合理替代句可接受，單一名詞或 because 片語不算完整成功。家長只依揭曉前表現選 Got it／With help／Not yet；提示後跟讀不算獨立。
- 語音指定 OpenAI Marin、speed 1.0；只把原創問題和答案送出製作。spokenQuestion 採連貫問句，避免短獨立尾句在合成時遺漏。
- 本作者已通過現行 core schema、Build／Change／Fix 順序、標準答案、唯一修正 pair、單字卡、全英文與語音未含完整答案檢查。獨立 review、TTS 音文一致、瀏覽器與發布是後續整合驗證，不以內容寫完冒充通過。
