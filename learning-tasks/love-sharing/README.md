## 使用與設計

孩子依序選「陳奶奶、狗醫生、服務、幫助、分享」的短詞，各選一組說法，不計分。主枝對應文章段落，保留奶奶的轉變、嘟嘟受訓、服務人的對象與地點、陪伴及復健的幫助、奶奶每週帶狗分享愛的行動。完成圖從中心向外抄，不在孩子畫面顯示字數。

家長於 2026-09-29 回報：上次〈悠閒午後〉的心智圖老師沒有修正。本次沿用其閱讀負擔與段落完整度；這是上次作業的教學回饋，不代表本篇已由老師確認。

## 來源與再製

- `source/coverage.md`：正文與各主枝的對照、取捨與驗證紀錄。
- `source/`：HTML、CSS、互動程式、文章短詞與 manifest 的可編輯來源。
- `build.mjs`：生成 `docs/love-sharing-mind-map/`，部署產物不要手改。
- 字型沿用 `docs/assets/fonts/BpmfZihiSans-Bold.ttf` 與既有授權；語境選音沿用 `docs/mind-map-reading.js`，本篇補充寫在 `source/content.js`。

重建：`node learning-tasks/love-sharing/build.mjs`。以靜態伺服器提供 `docs/`，開啟 `/love-sharing-mind-map/`。首頁文章索引位於 `docs/registry.json` 的 `mindMaps`，依日期預設最新篇；舊篇入口與存檔保留。從孩子首頁進入時保留 `?child=`，回首頁仍是同一位孩子。

進度只存在目前瀏覽器，使用獨立存檔名稱，沒有離線或跨裝置同步。iPad 真機、主畫面 App 與額外列印驗收沿用家長已略過的決定，不重列為使用門檻，也不記為已測通過。
