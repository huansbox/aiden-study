## 畫風比較

私用預覽放在 Dropbox `mywork/aiden-study/taigi-bitter-melon/style-mocks/`。用相同的試吃情節比較 10 種畫風，每組先看到孩子嚐到微苦的反應，再看到吞下後發現回甘。家長挑選畫風後，先做短動畫驗證，再從第一段開始製作練習。

## 朗讀時間軸

採學校講稿與原音。紙本內容決定畫什麼，原音時標決定何時亮字幕和觸發關鍵動作。字幕在句首先顯示完整句子，讀到的漢字逐字亮起，台羅按音節亮起。畫面按意思安排動作及鏡頭，不為逐字高亮切鏡。

做法參考[以配音為時間軸](https://tldr.linshuhuan.com/ai/2026-10-27-wenq26-g30s/principle/)。校方講稿、原音、時標及預覽成品留在私用資料夾。
