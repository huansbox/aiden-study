# 驗證範圍與證據

本文件說明首版交付的證據範圍；目前進度、PR／發布結果及後續回饋以 [Issue #220](https://github.com/huansbox/aiden-study/issues/220) 為準。

## 科學與程式

- `tests/test_water_cycle.mjs` 的 10 項測試涵蓋雲但無雨、雨滴合併長大、雪穿過厚暖層完全融化、冰雹兩條件四種組合、地面多路線、狀態重設隔離，以及兩語音稿／音檔可達與來源／成品一致性。科學預期依 `design.md` 的 USGS／NWS／NOAA 資料。
- 進階額外驗證固定起始水量、時間、空氣與風的定性蒸發比較，以及保留冰雹四組實際試驗紀錄；初階沒有這兩項額外負擔。
- `build.mjs --check` 逐檔比對網站與正式素材；語音 builder 的 `--check` 驗證 55 段中文、26 段英文 MP3 的文字指紋、hash、完整解碼與非靜音，共 81 段，不發出生成請求。
- 整個 repo 的 Python 檢查為 279 passed、1 skipped。首次完整 Node 檢查為 978 passed、1 failed，失敗是作品目錄仍保存選風格前的狀態說明；重建目錄後的結果與 CI 記於原 Issue。

## 瀏覽器與操作

`tests/helpers/water-cycle-browser-check.mjs` 連到既有 loopback server，以真實 HTMLAudioElement、音量 0 驗證；不以替換 `play()` 當作成功播放。

- Chromium：1024×768、1180×820、768×1024、390×844。兩版各站、回顧、自由換站、重設、主要觸控目標與橫向溢出均檢查。
- 語音：播放、暫停／繼續、0.8 倍速、重播、切站／回首頁停止；延遲載入時按暫停，以及多段操作提示的下一段載入時暫停，保留後段佇列。
- 觸控：fresh mobile context 的第一次操作就是長按。按住不載音，放開才播放中文說明，不誤進模式；移出、拖動、touchCancel 後的下一次正常點擊與鍵盤 Enter 可用。
- WebKit：獨立程序的 1024×768 雙版全流程完整通過，包含真實語音、解碼失敗與重試。第一次完整 runner 在英文冰雹後遇到 browser connection 關閉，原因未確認；該失敗另行保留，沒有推定為環境原因。最終共有 Chromium 四尺寸、fresh mobile touch、WebKit 共六個成功情境。
- 音檔失敗：Chromium 注入 HTTP 503；WebKit 原生媒體可能繞過網路攔截，改用真實 MPEG 解碼錯誤驗證錯誤提示與重試。背景停止以明確派送的 pagehide 驗證 handler。

代表畫面已人工目視，包含首頁、初階水窪、未選空氣的中性雪畫面、英文蒸發比較、冰雹試驗紀錄與回顧。

## 語音與獨立審查

- 以本機 Whisper 模型抽查 3 段中文與 6 段英文科學旁白，未將預期文字當 prompt；模型、文字及音檔 hash 保存於 `audio-{zh,en}-asr.json`。這是辨識輔助，不能等同人耳驗聽。中文辨識歧義促成兩段改用更直接措詞後重新生成／抽查。
- Claude 以獨立乾淨 context、唯讀工具審查。確認的缺陷已處理：首頁方向語音、冰雹準備好後的播放提示、雪未選條件先顯示冷空氣結果、長按取消與首次觸控播放、載入中暫停，以及首頁／地圖／重新旅行／太陽按鈕的語音指涉。修正後以對應瀏覽器情境及單元測試回歸。

## 保存與限制

非 Git 驗證附件位於 Dropbox 相對路徑 `mywork/aiden-study/water-cycle/validation-2026-10-20/`，包含原始獨立審查、測試紀錄、瀏覽器報告與少量代表截圖。機器根目錄查核方式見 `style-brief.md`。本機保存並核對內容，不代表已在其他裝置確認同步。

瀏覽器模擬不是 iPad 真機；合成觸控不是孩子操作。尚未驗證孩子的理解、英文難度、長期學習成效、全段人耳驗聽及 iPad 的實際音訊／背景政策。家長與孩子試玩後，依卡住的步驟或句子調整，不以工具測試替代。
