# 滿版互動繪本設計基準

本次重做依 [#225](https://github.com/huansbox/aiden-study/issues/225)：降低科學與文字負擔，改為在大插圖裡直接點物件。舊 #220 的六站實驗、條件表與輪流標記已被取代。

## 目前範圍

- 家長陪 6y、9y 中文共看；9y 的 English 先以容易短句起步，可自行或陪同。不用英文口述當概念理解門檻。
- C 紙張拼貼。每次 1–2 個短句，約 5–10 秒旁白；孩子直接看圖、聽聲音與操作。水滴主角是虛構角色。
- 整個 viewport 是故事，無側欄、長文字、實驗表、六站地圖、底排操作鈕、Predict／Try／Compare 或輪流標記。
- 只有低干擾翻頁、重聽／暫停、角落家長選單。觸控目標至少 48px；字幕預設關閉，長說明、中文支援、設定、來源與 AI 揭露收進 panel。
- 不依賴 Fullscreen API。平板橫向主、手機直向可玩，沒有橫向溢出。背景與熱區不可因裁切失配；河谷同一百分比映射，前景角色在各尺寸重新配置。
- 拖曳有點選替代；鍵盤 Tab／Enter 可操作、方向鍵翻頁。遵循系統 reduced motion，減少動作時仍保留結果。
- 所有旁白有固定稿與預製 MP3；單一 Audio，不疊音。可重聽、暫停載入中或播放中、0.8 倍速、切頁／背景停止，拒播或網路失敗可重試。

## 頁面與可重玩互動

| 頁 | 畫中操作與結果 | 科學界線 |
| --- | --- | --- |
| 封面 | 點故事水滴或中文入口開始；English 另選 | 不靠識字才知道有角色可碰 |
| 池邊 | 點太陽，整片水窪隨時間縮小；點水面有漣漪 | 蒸發不需沸騰；真實水蒸氣不可見，不畫霧、可見蒸氣粒子 |
| 雲 | 摸／拖雲，顯露放大的小水滴 | 涼空氣中凝結；有雲不一定下雨，不從此頁直接生成雨 |
| 雨 | 拖兩滴碰合或點水滴，先靠攏成單一較大水滴再下落；點葉搖擺 | 雲不是裝水的容器；碰合是簡化示意，不宣稱僅兩滴就足以形成真雨 |
| 雪 | 雲中雪花可點／滑而飄落；手套初始空白，接雪後才有雪；English 此時才顯示暖陽融雪 | 雪在冷雲中長大，不是雨滴結冰；暖陽是手套上的地面融雪 |
| 冰雹 | 點或向上拖冰粒，風托住；再點讓小水滴可見地靠近、凍上並長大；長大後上拖維持托住，點或下拖落雹；落地保留大雹與風，另出現新小冰粒重玩 | 雷雨雲強上升氣流與過冷水滴的科學細節留家長面板，不畫每顆都必須反覆繞圈 |
| 河谷 | 以不重疊多邊形貼合實際河流、左右泥岸、平靜水面，主要水／土區可點；角色沿河、滲土或休息 | 沒有必走的固定循環，各路可任意重玩 |
| 結尾 | 再玩／換語；家長選單仍可跳頁 | 不作掌握度評分、不在途中彈獎勵 |

## 文字與素材來源

旁白正本是 `content.json` 的 `voices`，每語言 21 段，新 ID 採 `zh-book-`／`en-book-`，避免把舊音訊誤當新稿。家長面板文字在 `pages[].parent`。背景是原創 AI 圖片，互動由程式畫 SVG／DOM；不複製參考網站程式或素材。

沿用查核依據：

- [USGS 蒸發](https://www.usgs.gov/water-science-school/science/evaporation-and-water-cycle)
- [USGS 凝結、水蒸氣與雲](https://www.usgs.gov/water-science-school/science/condensation-and-water-cycle)
- [NWS 雪晶與下降路徑](https://www.weather.gov/lmk/winter-precip)
- [NOAA 冰雹](https://www.noaa.gov/jetstream/hail)

## 驗證界線

以真實可玩行為驗證故事結果、重玩、拖曳／鍵盤替代、觸控可達、語音停止與失敗復原；測試不要求舊實驗表或特定 DOM 排列。科學機制要同時出現在動畫與適量的故事／家長說明，不只改狀態後靠旁白宣稱發生。

家長目視、音訊工具驗證、自動瀏覽器、孩子理解及 iPad 真機試玩分開記錄。舊六站畫面與語音的驗證不適用此版。

翻頁後焦點移至新頁首個適當物件，鍵盤可連續翻頁並以 Enter 操作。768×1024 直向 iPad 另核對雷雨雲與初始冰粒的相對位置；河谷直向拉伸是維持百分比配準的選擇，不代表所有直向美術都已完美。
