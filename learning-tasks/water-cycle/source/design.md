# 水循環設計基準

## 已確認需求

- 一份作品、兩個版本。初階供家長與 6y／9y 共看；進階供 9y 自己或家長陪同。
- 平板橫向優先。可自行翻頁、暫停／重播；觸控目標夠大，拖曳須有點選替代操作。實際尺寸依原型驗證調整。
- 初階採互動故事：一起猜、輪流操作、看結果、短討論。先讓兩人各自表達再揭曉，不指定哥哥負責教弟弟。
- 初階入口、操作、提示與回饋不能依賴識字；網站負責旁白與示範，家長負責陪看與接話。
- 進階從 Native Camp 目前課程／Oxford Discover 1 相關內容作語言起點，先容易、有趣再依實測調整。家長表示課程偏容易，不代表已有長篇英文科普閱讀能力的證據。
- 科學深度與語言負擔分開：科學可透過操作、比較與證據加深；英文先短句、具體指涉，術語有圖解與中文支援。
- 美術已由家長選定 C「紙張拼貼」：layered cut-paper、colored-pencil 細節與淺紙張陰影，兩版共用。正式畫面減少草葉、石頭等碎細節，讓水的變化與操作更清楚。選定只代表美術方向，不等於孩子理解或平板使用已驗證。

## 初版故事範圍

1. 水窪變小：水去了哪裡？蒸發無須先煮沸。
2. 看不見的水：水蒸氣不可見，觀察示意要明確標記。
3. 進入雲中：小水滴或冰晶；有雲不一定下雨。
4. 雨與雪：粒子成長，雪在下降途中可能融化；不把雪教成雨滴簡單結冰。
5. 雷雨雲裡的冰粒：上升氣流、過冷水滴與冰粒成長；不可用單一冷熱控制雨→雪→冰雹。
6. 回到地面：水流、融雪、滲入土壤與停留的不同路線，沒有每滴水必走的固定圈。

故事將雨、雪、冰雹拆成清楚的情境，不要求孩子一次操作所有條件。科學動畫由程式控制，插圖提供角色與環境。時間加速、放大與模型簡化在適當位置說明。

## 英文與音訊

- 每次一個現象或動作；短句配圖，先描述再引入術語。英文起點是待孩子試用的設計假設，不是能力認證。
- 英文可重聽，詞彙可看圖解、聽發音、展開中文。科學回答可用操作／指圖，英文口述可選。
- 正式語音方式於實作時依臺灣中文與英文品質、裝置可用性決定，先不以瀏覽器存在語音 API 當成真機可用證據。旁白不得互相重疊，操作回饋不蓋過解說。
- 若接入家庭成果記錄，保存成果與顯示獎勵分開；完整故事／實驗回合結束才顯示獎勵。

## 驗證方式

- 初階：不讀字能否知道要做什麼、兩個孩子是否都有操作與表達機會、家長是否只需陪看與接話。
- 進階：短句配圖是否可理解、是否願意繼續玩；先分辨語言障礙與科學概念，不以英文說不出直接判概念不會。
- 科學：對照查核來源驗證各情境，包含雲但無降水、雪途中融化，以及冰雹所需條件。
- 平板：操作尺寸、橫向顯示、縮放、語音啟動／暫停／重播與不重疊，依實際瀏覽器與真機分開記錄。
- 所有自動化驗證與合成作答只證明程式行為，不當作孩子學習成效。
