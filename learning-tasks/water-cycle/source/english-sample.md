# English 繪本用語

目前採用稿與中文對照，以 [content.json](content.json) 的 `voices` 為唯一正本；每語言 21 段，採 `en-book-`／`zh-book-` 新 ID。這份文件不再維護另一套樣稿。

English 跟中文看同一個簡單故事，以看圖和動作先理解。家長選單可開中文對照、聽中文、字幕或 0.8 倍速。額外探索是點暖陽讓手套上的雪融化；數雪花尖角是可選短提問，不設答題門檻。

英文起點是依家長提供的 Native Camp 經驗作設計假設，尚非孩子理解或獨立閱讀能力的評量。舊六站深入研究稿請查 Git history，不應拿來重新產生此版語音。
