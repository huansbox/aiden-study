# 同場景三種美術初稿

## 固定內容

三張都是 16:9 橫向、供 6y／9y 與家長共看的親子科學故事。比較的是筆觸與材質，不以不同故事、配色主題或角色陣容影響選擇。

固定場景：晴朗山谷，左下前景有草邊的小水窪與一顆圓石；溪流通過綠色丘陵往遠方小湖延伸；右上淡藍天空有一朵白雲。左上留有自然、安靜的空間，供後續程式疊字與操作。右下邊緣有一個小型水滴故事嚮導，以簡單眼睛與微笑呈現，和真實水體分開。嚮導是故事角色，不是水分子的真實外觀。

不生成文字、UI、箭頭、科學圖解、蒸氣白霧、雨雪冰雹或其他擬人角色。科學圖解在後續用程式獨立繪製。

## 變體

| 候選 | 媒材 | 要比較的感受 |
| --- | --- | --- |
| A | 柔和不透明 gouache＋少量 colored-pencil，溫暖細緻紙紋 | 溫暖、輪廓清楚的手繪繪本 |
| B | 透明 watercolor＋細 graphite 輪廓、輕紙紋 | 透亮、較輕盈的自然觀察感 |
| C | layered cut-paper＋colored-pencil 細節、淺層紙張陰影 | 材質清楚、形狀容易辨識的手作拼貼 |

三張均為 AI 製作的審稿初稿。家長已選 C「紙張拼貼」為正式製作方向，後續減少草葉、石頭等背景碎細節。生成時機制與外部參考 repo 的 Gemini 網頁工作流不同，本次使用 Codex 內建 imagegen；未使用外部 repo 的圖片或程式。
