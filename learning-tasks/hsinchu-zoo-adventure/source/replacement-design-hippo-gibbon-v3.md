# 河馬／長臂猿替換題：v3 候選規格

> 狀態：Gate 1R 與 Gate 2R 均已通過（2026-08-13）。

## 退回原因

- 河馬 v2：生成圖為簡化 diagram，與其餘卡的寫實 field-guide 畫風不一致；題目只比「眼耳在上或在側」，對 5.5 歲仍太容易。
- 長臂猿 v2：雖形式上有手臂長度與尾巴兩個線索，但只有選項 2 有尾巴，視覺差異過強，孩子可不比較手臂就先排除。
- 其餘六張卡與地圖維持不動。

## 河馬候選

### H1：河馬腳印拼圖（第一輪退回）

題目：「先看河馬的腳，再找出牠踩下去的腳印。」

卡面上方先放一張寫實河馬腳近照／插圖，只露小腿末端與腳：四根短趾自然張開，每趾前端有寬圓趾甲。下方三個選項都畫正上方腳印，使用相同大小、方向與深淺：

1. 四個短圓趾印，前端有四個寬圓趾甲痕。
2. 四個短圓趾印，但前端是四個細長尖爪痕。
3. 三個短圓趾印，前端有三個寬圓趾甲痕。

答案 1。交叉干擾是「四趾」出現在 1、2；「寬圓趾甲」出現在 1、3，必須同時比趾數與趾甲形狀。

圖像限制：

- 參考腳統一為斜上方三分之四視角，四趾互不遮疊；選項統一為正上方理想化印痕，題幹明說是「踩下去的腳印」。
- 參考圖不得出現河馬頭、嘴、身體、水面或棲地。
- 選項不得用腳印大小、泥土背景、顏色或深淺洩答。
- 不要求現場看清腳底；卡片本身提供作答線索。若現場看得到腳趾，可作額外發現。

風險：真實印痕受泥地與步態影響，不保證四趾／趾甲都清楚，因此不能宣稱「現場一定踩出這種完整腳印」；卡片需表述為依參考腳做形狀配對的理想化拼圖。

第一輪 reviewer 結論：河馬四個承重趾與寬鈍圓蹄狀趾甲正確，但真實足印不保證留下四枚清楚、分離的趾甲痕；兒童題幹仍會把理想圖誤解成自然必然。此版不採用。

### H1R：河馬腳趾密碼（修訂推薦）

題目：「先看上面的河馬腳，再找出放大的同一隻腳。」

卡面上方放一張寫實河馬單腳 close-up，只露小腿末端與腳，採斜上方三分之四視角：四根短趾自然張開、互不遮疊；每趾末端都有一枚寬鈍、圓蹄狀趾甲。下方三選都畫同一視角、同一大小與同一外框的放大腳部：

1. 四個短趾＋四枚細長尖爪。
2. 四個短趾＋四枚寬鈍圓趾甲。
3. 三個短趾＋三枚寬鈍圓趾甲。

答案 2。交叉干擾：「四趾」出現在 1、2；「寬鈍圓趾甲」出現在 2、3，任何單一線索都無法唯一作答。

圖像限制：

- reference 與三選一律採相同斜上方三分之四視角；只露腳和少量小腿，不畫泥印、足底、頭、身體、水面或棲地。
- 四趾都須自然張開並逐一可數；趾甲與趾端相連，寬鈍但不可畫成馬的一整塊蹄。
- 三選的毛／皮膚、腳掌輪廓、明暗與占圖大小一致，只改趾數與趾甲形狀；選項 3 不得因少一趾而整體變窄或偏位。
- reference caption 只提示「先數有幾根，再看前端形狀」，不得寫出四趾或寬圓答案。
- 卡片本身提供作答線索；不要求現場看清河馬腳。若現場看得到一根趾或圓趾甲，只算額外發現，隨時可收卡。

### H2：河馬鼻孔雙線索

題目：「哪一張同時放對了河馬的鼻孔和嘴巴？」

三張相同寫實正面寬吻，只改鼻孔方向與嘴巴寬度：

1. 鼻孔朝上＋寬嘴。
2. 鼻孔朝前＋寬嘴。
3. 鼻孔朝上＋窄嘴。

答案 1。交叉干擾：朝上鼻孔出現在 1、3；寬嘴出現在 1、2。

風險：現場常不是正面，且「寬嘴」可能仍過於顯然；若沒有同角度照片，容易中斷。

### H3：河馬耳朵形狀配對

題目：「哪一對耳朵和河馬最像？」

只畫相同尺度的耳部近照，選項比較小而圓、長而尖、寬而下垂。優點是可畫得寫實；缺點是單線索，難度可能仍不足，不推薦。

## 長臂猿候選

### G1：猿手握樹枝（第一輪退回）

題目：「先看長臂猿的手，再找出牠抓樹枝的方式。」

卡面上方先放一張寫實長臂猿手部近照／插圖：長而彎曲的四指包住橫枝，拇指位於較低處、與四指相對。下方三選都使用相同手腕、橫枝、視角與大小：

1. 四根長而彎曲的手指包住樹枝＋一根較低的相對拇指。
2. 四根短直手指放在樹枝上＋一根較低的相對拇指。
3. 四根長而彎曲的手指包住樹枝＋拇指和其他手指排在同一側。

答案 1。交叉干擾是「長彎手指」出現在 1、3；「相對拇指」出現在 1、2，需同時比兩項。

圖像限制：

- 只露手掌、手指、少量手腕與同一根中等粗細橫枝；不得出現頭、軀幹、手臂長度或尾巴。
- 三張統一為斜上方三分之四視角，五指都能逐一看清，拇指不可被枝幹遮住。
- 參考圖與選項同視角；卡片本身提供作答線索，不要求動物維持特定抓握姿勢。
- 現場若看見手抓繩索／樹枝，可作額外發現；看不到也不等待。

風險：長臂猿拇指相對較短，抓握與 brachiation 時不一定每次都以人類式環抱呈現；插圖須以解剖正確的手部 close-up 為準，不能畫成人手。

第一輪 reviewer 結論：長而彎曲的四指與短而可對握的拇指正確，但 brachiation 時拇指可能收在四指同側；因此不能以拇指繞枝方向判斷唯一正解。此版不採用。

### G1R：長臂猿抓握手（修訂推薦）

題目：「先看上面的長臂猿手，再找出放大的同一隻手。」

卡面上方放一張寫實長臂猿手部 close-up，採斜上方三分之四視角、手掌放鬆微彎：手掌狹長、四指纖長而彎曲；拇指比四指短，拇指基部靠近手腕，與食指間形成明顯較深的虎口裂隙。下方三選使用同一手腕、同一視角、同一手掌外框：

1. 四指短而較直＋拇指基部低、靠近手腕，虎口裂隙深。
2. 四指纖長彎曲＋成人手式高位拇指，拇指基部靠近食指，虎口裂隙淺。
3. 四指纖長彎曲＋拇指基部低、靠近手腕，虎口裂隙深。

答案 3。交叉干擾：「長彎四指」出現在 2、3；「低位拇指基部／深虎口」出現在 1、3，必須同時比較。

圖像限制：

- reference 與選項只露手、手腕，不畫頭、身體、完整手臂或尾巴；不畫樹枝，避免抓握姿勢變成答案。
- 三張斜上方三分之四視角完全一致；五指都完整可見，指尖有扁平指甲，不畫成人手的厚掌與短指。
- 手掌皆維持同樣狹長外框；選項 1 只縮短／拉直四指，不讓整隻手縮小；選項 2 只移高拇指基部並縮短虎口裂隙。
- reference caption 只提示「先看手指形狀，再找拇指從哪裡長出來」，不使用孩子不需理解的「相對拇指／虎口」術語，也不直接說長、低或深。
- 卡片本身提供作答線索；現場看見手抓繩／枝僅算額外發現，不要求等待特定手勢。

### G2：長臂猿肩部活動拼圖

題目：「哪個肩膀能讓手臂往頭頂上方伸？」

使用相同骨架／輪廓，改肩胛與上臂方向。缺點是抽象、接近人體解剖教學，5.5 歲不易從現場觀察，不推薦。

### G3：長臂猿移動路線

題目：「哪一條線最像牠從這根枝盪到下一根？」

比較向下弧線、直線、折線。缺點是答案依賴當下行為且可能長時間不移動，不推薦。

## 初步選擇

- 河馬採 H1R「河馬腳趾密碼」。不再把理想圖誤稱真實足印；改用同視角 reference 直接比四趾與寬鈍趾甲。
- 長臂猿採 G1R「長臂猿抓握手」。不再用隨動作改變的拇指繞枝方向；改比穩定的長彎四指、低位拇指基部與深虎口。

兩題都允許只在卡片上完成，現場找到同一特徵僅算額外發現；因此中斷、跳過或動物未現身不會形成未完成壓力。

整組答案位置刻意錯開：既有狐獴 reference 配對題答案為 1，H1R 河馬為 2，G1R 長臂猿為 3；孩子不能沿用「reference 題都選同一格」的規律。

## Gate 1R 驗收

1. 動物解剖／足印與手部特徵正確，不把理想化圖形誤說成每次現場都會出現。
2. 5.5 歲不能靠唯一突兀特徵或題目名稱秒答；必須合併兩項線索。
3. 不需識字、先備知識或等待動物擺出特定姿勢。
4. 三選圖同視角、同尺度、同背景，只改指定兩項特徵。
5. 在卡片上可完成；現場只做額外觀察，隨時能收卡。
