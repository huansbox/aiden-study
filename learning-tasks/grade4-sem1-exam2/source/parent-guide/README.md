# 家長快速掌握清單

由 [#255](https://github.com/huansbox/aiden-study/issues/255) 追蹤，沿用本 task，不新增孩子 App。

- `content.json`：可編輯的原創重點、確認例與考法摘要；穩定項目 ID 對應本機勾選，改變能力意義時請換 ID。
- `template.html`、`guide.css`、`guide.js`：頁面來源。
- `build.mjs`：產生 `docs/parent/exam2-guide/`。在 repo 根目錄執行 `node learning-tasks/grade4-sem1-exam2/source/parent-guide/build.mjs`，加 `--check` 檢查一致性。
- 家長從 `/parent/` 固定入口或作品白板進入。沒有家庭 API、孩子身份、正式成績、音效或獎勵；只有本瀏覽器 localStorage 的家長勾選。
- 私人逐項證據、實際視讀原頁、原件 SHA 與 QA 位於 Dropbox 相對路徑 `mywork/aiden-study/grade4-sem1-exam2-parent-guide-2026-11-07/`。原卷題文、圖片與答案不發布。

沿用 [上次數學分類報告](../../../../docs-dev/grade4-math-pattern-counts.md) 的「單元→概念→推理／作答方法」；不沿用活動數做考試頻率。原卷觀察分桃子腳、跨校；確認問題均為原創，不能當作學校原題。範圍仍暫定，不等於完整課綱或正式考範。

紙本能力須保留：三角板／直尺量畫、統計圖、直式、列式、電路自由畫圖與自行舉例。缺損題、條件衝突及本輪範圍外題不納入；電路亮度依同規格材料與相同電池條件說明，不能照抄有問題的強迫排序。

目前共37項（數學23、自然14）。三角形角性質依115康軒計畫確認；歷屆用內角和求缺角另標延伸，不作本輪勾選條件。新項目與無JavaScript列印說明的證據、驗證另存上述私人目錄 `v2/`，原 `freeze-v1/` 保留。
