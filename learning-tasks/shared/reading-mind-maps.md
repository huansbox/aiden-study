# 兒童閱讀心智圖：可重用做法

適用於 9 歲孩子用 iPad 讀文章、用自己的話做心智圖，最後抄到作業本的一次性閱讀任務。共用流程以 [〈付出比收穫更可貴〉](../giving-more-precious/README.md) 確認的做法為準，各篇另記內容與驗證結果。

## 每週交付素材

每週換一篇新文章，孩子首頁的「心智圖」預設開日期最新的已發布文章；「過去文章」可選舊篇，選取不改變下次預設。家長提供文章全文或依頁序的清晰照片，包含原題與所有正文；老師另有格式要求、必留重點或上次批改時再一併附上，沒有就省略。照片看不清或缺頁才補問，不要求家長先整理主枝、選項或段落摘要。

可直接複製以下文字並附上材料；若對象不同，把孩子名字換掉：

> 請替煦誠製作本週閱讀心智圖。文章全文或清晰照片附在這則訊息，有老師要求或回饋也一起附上。保留大字注音和從右上第 1 枝順時針的放射樹狀圖。用 9 歲孩子會說的白話抓重點，每枝都能「改成我的話」。內容交給 Claude Sonnet／medium 對照原文審查。完成審查與驗證後，直接發布並加入文章索引，讓煦誠首頁的「心智圖」開這篇新文章。

這段交付文字包含發布與更新文章索引的授權；同一次工作已有授權時直接沿用，不逐步重問。若本次只要預覽，將最後一句改為「先完成本機預覽」。新文章仍由 agent 讀材料、製作互動內容；家長後台沒有上傳文章後自動生成的功能，也沒有每週自動執行排程。

## 每週製作與換入口

以下由 agent 完成，不另交一份每週真機驗收表給家長。

1. **讀原文，決定各枝重點。** 先讀 [任務索引](../README.md)、相近作品和 [老師回饋／段落對照](../leisure-afternoon/source/coverage.md)，再讀本週材料。依 [任務資料夾規格](../README.md#任務資料夾規格) 建立任務，在 `learning-tasks/catalog.json` 登錄並歸入 `reading-mind-maps` 系列，執行 `node scripts/build-work-catalog.mjs` 產生任務索引與白板。主枝數與名稱依文章決定。在 `source/coverage.md` 簡記各段必留內容、可取捨的細節及老師要求。
2. **製作放射圖與改寫引導。** 每篇都以原題為中心往外連主枝與短句。第 1 枝固定在右上，其餘枝依文章順序順時針排列，故事依情節發展排序。引導預覽、完成抄寫圖與列印都用這個放射樹狀版型，手機或長句沿各自分枝換行。選題步驟、圖上編號與抄寫順序一致。每枝按下方「孩子怎麼操作」設計白話引導及「改成我的話」。保留獨立 `source/`、`build.mjs`、部署目錄、存檔及 [回首頁處理](../../docs/shared/task-home.js)。
3. **交給 Claude Sonnet／medium 獨立審查。** 每篇在發布前把原文或照片、段落對照、問題、提示與白話例句交給 Sonnet，推理強度用 medium。請它直接對照原文，核對人物、起因、做法與結果是否清楚，例句是否像 9 歲孩子會說的話，改寫提示是否能幫孩子自己抓重點。確認並修正有原文依據且會影響理解的問題，必要時請同一規格複核，將結果記入該篇 README 或交付紀錄。
4. **驗證孩子實際怎麼用。** 跑本篇 build 與 `--check`。參照 [白話改寫版測試](../../tests/test_giving_more_precious_mind_map.mjs) 檢查例句涵蓋核心、讀音、草稿與完成存檔、來源與產物一致。跑本篇及受影響的測試。若改到共用讀音或首頁銜接，也跑 [舊篇](../../tests/test_mind_map.mjs)、[家庭設定](../../tests/test_family.mjs) 與 [入口連結](../../tests/test_family_client.mjs) 的測試。用瀏覽器走完採用例句、自寫、取消、重整保留草稿及完成後回改。從右上第 1 枝順時針讀一遍，用下方尺寸檢查引導預覽與抄寫圖的長句換行、文字和連線間距，以及按鈕可見。發布時仍須通過 repo CI。
5. **文章與索引一起發布。** 把一次性文章登記在 `docs/registry.json` 的 `mindMaps`，填 `id`、`title`、作業 `date`（YYYY-MM-DD）及站內相對 `path`。首頁以日期選新篇，同日沿用索引順序。執行 `node scripts/build-home-release.mjs`，依當次授權一起發布。確認正式 HTML 已更新，再核對它實際引用的內容、樣式、manifest 與字型。從孩子首頁開最新篇並回到原孩子，再用「過去文章」開舊篇，確認返回後預設仍是新篇。若本次只要求預覽，就交付本機預覽。
6. **留來源與驗證結果。** 補齊新篇 README、段落對照、審查及驗證結果，留一張已完成的抄寫圖。將 `learning-tasks/catalog.json` 狀態標為已完成並重建白板與 README。保留舊篇來源、索引、再製資訊與各篇原有進度。記錄實際驗證的範圍。

家長可在後台勾選各孩子是否顯示「心智圖」，再按「儲存全部設定」。後台顯示最新篇名，首頁也從文章索引取得新篇。入口與回首頁的行為見 [已發布的首頁機制](../../docs-dev/family-uiux-v2.md)。

## 孩子怎麼操作

- 每枝先問一個問題，讓孩子口頭說說看。需要幫忙時，可以打開收合的提示，找回原文裡的線索。
- 給 9 歲孩子平常會說的短詞或短句。該交代的「誰做了什麼、為什麼、後來怎麼了」直接寫進圖。篇幅依情節決定，先刪重複及次要細節。
- 每枝都可直接採用例句，或按「改成我的話」，沿著小問題改寫。讓孩子寫的句子進入預覽與抄寫圖。完成後點枝名可回改，重新整理能找回草稿與進度。參考 [〈付出比收穫更可貴〉的操作](../giving-more-precious/README.md)。
- 照片沒有標題時，標示圖中央是孩子選的摘要名稱。

## 案例差異不能省略

老師在〈一千根琴弦〉的批改要求從右上起順時針排列。故事順序和右上起的編號可參考 [〈正義女神阿絲特蕾亞〉](../astrea/README.md)。

舊作業採四條主枝，老師後來另補「貢獻」。這次〈悠閒午後〉因此安排五枝，並把「詩與照片的關係」「共同心意」獨立保留；不是把任何文章都硬塞進五枝。下次先讀 [老師回饋與段落對照](../leisure-afternoon/source/coverage.md)，依新文章決定哪些內容必留、哪些例子能讓孩子取捨。本次保留四種詩景的成組選項，也只適用於該段內容。

## iPad 與注音

- 橫向以左側選題、右側預覽；完成後放大整張圖。依實際可用高度排版，保留手動縮放。展開提示時允許捲動，不裁掉內容。
- 選題文字約 22px、標題約 26px，完成圖約 24～26px；選項與下一步按鈕至少 48px。字型含右側注音，不能只用中文字寬度估算。
- 字型唯一資產為 `docs/assets/fonts/BpmfZihiSans-Bold.ttf`（約 5.34 MB）。[來源與授權](../../docs/assets/fonts/README.md) 隨站保留，首次下載失敗要顯示退回中文字的提示。
- `docs/mind-map-reading.js` 處理顯示用多音字選音；新文語境額外規則放該任務內容中。〈悠閒午後〉另校正相通、相機、一行詩、看得懂、重新。不要把顯示用選音符號寫進選項或存檔，也不要改共用規則而誤傷舊文章。
- SVG 連線用實際文字盒量測，字型載入或畫面尺寸改變後重算。檢查文字盒相交與連線靠近文字的情形，不能只看一張桌面截圖。

## 來源、進度與部署

舊作業的唯一來源仍在 `docs/mind-map.*`。新任務沿用〈悠閒午後〉的組織方式：`learning-tasks/<task>/source/` 保存可編輯來源，`build.mjs` 產生 `docs/<entry>/` 部署檔；來源、產物一致性納入 Node 測試。這是檔案編排參考，兩個頁面尚未抽成共同應用程式。

每篇使用獨立的 LocalStorage key。自寫句子、草稿與進度保存在目前瀏覽器，還原完成圖前檢查各枝的必填內容與存檔格式。首頁顯示由每個孩子的 `mindMap.enabled` 決定，最新與過去文章由 `registry.json` 的 `mindMaps` 索引決定。舊家庭設定保留 `title` 與 `url` 供 Worker 相容。直接開文章可用自己的 manifest，從孩子入口進來時沿用平台 manifest 並保留 `child`。Safari、主畫面 App、localhost 與正式網域可能各自保存進度。透過連線開啟文章。

正式站為 `https://kids.linshuhuan.com/`，GitHub Pages 發布 `master` 的 `docs/`。原照片不公開入庫；保留必要摘要、段落對照、來源與一張代表性完成圖即可。上線後核對頁面、內容、manifest、字型與 CI，不靠本機預覽判定已發布。

## 驗證界線

兩篇既有任務已驗證選擇流程、回頭修改、重新整理還原、選項限制與字數，均做橫直向瀏覽器尺寸檢查。新任務沿用 1024×650、1024×768、1180×720、768×1024 與 390×844；較矮的 1024×650 用來檢查 Safari 留給頁面的空間。這是 agent 的版面檢查，不要求家長每週逐項操作真機。

這些是瀏覽器模擬尺寸，不等於 iPad 真機驗收。老師已批改舊作業可證明成品曾抄寫，不能據此補稱真機觸控、主畫面 App 或列印都測過。各篇記錄實際測過與略過的項目；〈悠閒午後〉已依使用者決定略過額外真機與列印驗證，不列待辦。
