# 任務共用資源

本目錄只保存已在至少兩個不同家庭學習任務實際重用的原則、模板或素材。

## 已收錄

- [兒童閱讀心智圖](reading-mind-maps.md)：每週素材交付格式與製作、發布、替換目前入口的流程；另保留兩次任務重用的選詞、粗體注音、iPad 版面、獨立存檔，以及文章主枝不可直接套用的界線。
- [Native Camp 共用工具與流程](nativecamp/README.md)：已由 9/14、9/16 等不同課程重用的題包建置、原創語音製作與來源核對工具；每堂題文、證據及私人來源仍留在各自任務。
  - 設計入口：[課程製作 SOP](../nativecamp-review-pilot/lesson-sop.md)／[課程 brief 模板](../nativecamp-review-pilot/templates/lesson-brief.md)。目前唯一來源仍在首堂試作，不另複製。
  - 週題入口：[每週規劃 SOP](nativecamp/weekly-planning.md)／[每週自動化 SOP](nativecamp/weekly-automation.md)。沿用時先確認來源、已教概念與驗收界線，不把工具驗證當成孩子掌握度或人耳驗聽。

第一次產生的做法先留在原任務；第二個任務重用並確認適用邊界後，再提煉到這裡，並讓兩個任務 README 都連回共用資源。

提升時應記錄：

- 已在哪些任務使用。
- 哪些部分可直接重用，哪些仍須依年齡、場地或媒材調整。
- 真相源、授權與再製方式。
- 驗證方式，以及已知不適用情境。
