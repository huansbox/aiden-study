## 題目安排

### story-about：What is the story about?

Build 用 It is about…；Change 改問句字序 Is it about…，不是換主題名詞。Say 接受語意相符的完整預測。

| 題目 | 示範答案 |
| --- | --- |
| `story-about-try-1` | It is about a lonely bird. |
| `story-about-try-2` | Is it about a lonely bird? |
| `story-about-try-3` | It is about a lost kitten. |
| `story-about-say-1` | I think it is about a lost cap. |
| `story-about-say-2` | Is it about a lonely rabbit? |
| `story-about-say-3` | I think it is about two new friends. |

### can-help：Can you help?

Change 的箱子從輕變得太重，can 改 cannot；Fix 只修正 can 後的動詞原形。口說情境明示是虛構故事。

| 題目 | 示範答案 |
| --- | --- |
| `can-help-try-1` | The rabbit can lift the box. |
| `can-help-try-2` | The rabbit cannot lift the box. |
| `can-help-try-3` | The bird can find its nest. |
| `can-help-say-1` | The rabbit can help the duck. |
| `can-help-say-2` | The kitten cannot reach the nest. |
| `can-help-say-3` | They can carry the box together. |

### feelings-because：Feelings and reasons

Change 從一人改為兩人，連動處理 are、they、find、their；不是只回答 Because…。

| 題目 | 示範答案 |
| --- | --- |
| `feelings-because-try-1` | Mia is happy because she finds her dog. |
| `feelings-because-try-2` | They are happy because they find their dog. |
| `feelings-because-try-3` | Ben is sad because he cannot find his toy. |
| `feelings-because-say-1` | Lily is happy because she has a new friend. |
| `feelings-because-say-2` | They are scared because a lion is chasing them. |
| `feelings-because-say-3` | Ben is lonely because he has no one to play with. |

### near-far：Near or far?

Change 同時從手中一枝鉛筆變成遠處兩枝；所有畫面寫清楚 near／far，Say cue 只列可能句首，未預選答案。

| 題目 | 示範答案 |
| --- | --- |
| `near-far-try-1` | This is a pencil. |
| `near-far-try-2` | Those are pencils. |
| `near-far-try-3` | These are books. |
| `near-far-say-1` | That is a book. |
| `near-far-say-2` | These are oranges. |
| `near-far-say-3` | Those are birds. |

### pet-description：Tell us about a pet

Change 從本人 I have 轉述成 He has；Say 將寵物與一到兩個特徵合成完整句。

| 題目 | 示範答案 |
| --- | --- |
| `pet-description-try-1` | I have a small rabbit. |
| `pet-description-try-2` | He has a small rabbit. |
| `pet-description-try-3` | They have two green lizards. |
| `pet-description-say-1` | She has a white kitten. |
| `pet-description-say-2` | They have two small goldfish. |
| `pet-description-say-3` | I have a big brown dog. |

## 作答與語音判準

- 所有故事人物、寵物、物品、數量與所有關係均為虛構。畫面／語音提供本題必要資訊，不要求孩子回想未提供的教材圖片或私人生活。
- 排列卡是單一單字，每題一個或兩個混淆字；instruction 明示剩餘卡數與必要句首，避免較短但語法成立的子句被誤認完整答案。自然字序仍須符合卡片中的人物、視角、事實與因果。
- Fix 只換一個詞，不同時藏兩個錯誤；第三題是同一能力的補強。
- Say 要說出本題指定資訊的完整句；縮寫、同義說法及自然合理替代句可接受，單一名詞或 because 片語不算完整成功。家長只依揭曉前表現選 Got it／With help／Not yet；提示後跟讀不算獨立。
- 語音指定 OpenAI Cedar、speed 1.0；只把原創問題和答案送出製作。spokenQuestion 採連貫問句，避免短獨立尾句在合成時遺漏。
- 本作者已通過現行 core schema、Build／Change／Fix 順序、標準答案、唯一修正 pair、單字卡、全英文與語音未含完整答案檢查。獨立 review、TTS 音文一致、瀏覽器與發布是後續整合驗證，不以內容寫完冒充通過。
- 完成課程收起；新 Weekly Review 只在家長另行要求時製作。本課沒有建立或恢復排程。人耳全檔自然度、iPad 真機與孩子難度／耗時尚未測。
