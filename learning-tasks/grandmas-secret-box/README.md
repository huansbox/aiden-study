## 內容審查

Claude Sonnet／medium 對照原照，指出哥哥想帶盒子的理由和結尾的「爺爺」需要更清楚。已補上哥哥希望寶貝盒子能陪奶奶、生日合照中的牽手，以及收好相片後帶著「爺爺」去醫院。複核確認例句符合原文情節。

注音以課文與字嗨 v1.500 選音表核對，親屬稱呼與「盒子」的輕聲只套用在畫面。另參照教育部國語辭典的[奶奶](https://dict.concised.moe.edu.tw/dictView.jsp?ID=12189&q=1)、[盒子](https://dict.concised.moe.edu.tw/dictView.jsp?ID=19096&la=0&powerMode=0)、[相片](https://dict.concised.moe.edu.tw/dictView.jsp?ID=28066&la=0&powerMode=0)。

## 瀏覽器驗證

隔離 Chromium 驗證家長後台最新篇、孩子首頁開新篇、回首頁、舊篇進度隔離及回到預設新篇。驗過採用例句、回上一枝、自寫必填、取消、重整還原草稿與完成進度，以及完成後點枝名回改。

引導預覽和抄寫圖驗過 1024×650、1024×768、1180×720、768×1024、390×844 的順時針順序、注音字型、文字及連線間距、長句換行與操作按鈕。另驗證字型下載失敗的提示，以及 Chromium A4 橫向單頁列印預覽。窄螢幕和較矮視窗可上下捲動。驗證範圍為瀏覽器模擬，iPad 真機與主畫面 App 未實測。
