## 五個概念與六題安排

### `friends-pets`：A friend's pet

目標是用完整句表達誰擁有什麼寵物；易混淆處是第三人稱單數 has 與 I／they 的 have。短 cue 只提供主詞，不提供待選動詞。

| 題目 | 內容／答案與判準 |
| --- | --- |
| `friends-pets-try-1` | Sam 的寵物卡；組成 `He has a hamster.`，have 為混淆字。 |
| `friends-pets-try-2` | 原先以 He 描述 Sam，現在扮演 Sam 自己說；改成 `I have a hamster.`，同時轉換主詞與動詞，保留同一隻寵物。 |
| `friends-pets-try-3` | Mia 與 Leo 共養一隻金魚；把 `They has a goldfish.` 的 has 改成 have，其他字不需變動。 |
| `friends-pets-say-1` | 依 Lily 的兔子卡說 `She has a rabbit.`；Lily 作主詞、She's got… 也可。 |
| `friends-pets-say-2` | 扮演 Max 介紹金魚；`I have a goldfish.` 或 I've got…，不可用第三人稱介紹別人。 |
| `friends-pets-say-3` | Ben 和 Kim 共養兩隻 guppies；`They have two guppies.`，名字作主詞亦可，數量需一致。 |

### `pet-reasons`：Why this pet?

目標是用 because 連接喜歡的對象與卡片給定理由。主句、原因子句與單複數指涉都要完整；`I … because …` 等 cue 沒有提供整句或原因。故事中的動物能力只是本題條件，不作照護或泛化承諾。

| 題目 | 內容／答案與判準 |
| --- | --- |
| `pet-reasons-try-1` | 喜歡一隻會說話的故事鸚鵡；`I like this parrot because it can talk.`。 |
| `pet-reasons-try-2` | 同時改為兩隻都會說話的鸚鵡；`I like these parrots because they can talk.`，需要 this／these、it／they 與名詞複數的連動判斷。 |
| `pet-reasons-try-3` | 單隻會玩的 kitten；只把 `I like this kitten because they can play.` 的 they 改成 it。 |
| `pet-reasons-say-1` | Mia 喜歡兔子柔軟的毛；完整表達 `Mia likes this rabbit because it has soft fur.`，its fur is soft 等自然原因句可接受。 |
| `pet-reasons-say-2` | 以故事卡的捉蚊子理由說 `I like these lizards because they catch mosquitoes.`；can catch 可接受。 |
| `pet-reasons-say-3` | Leo 喜歡會唱歌的鳥；`Leo likes this bird because it sings.`，He 作主詞或 it can sing 亦可。 |

不能只有 Because… 片語，不能把喜歡對象或理由換成卡片未提供的另一項。

### `pet-looks`：Describe a pet

目標是描述指定部位或尺寸／顏色，區分單一身體／毛與複數耳朵／腳。Try 檢查 is／are，Say 可接受同樣準確的 has 描述；不把字序完全相同當成唯一口說標準。

| 題目 | 內容／答案與判準 |
| --- | --- |
| `pet-looks-try-1` | 狗的身體黃、耳朵白；只描述身體：`Its body is yellow.`。 |
| `pet-looks-try-2` | 視角改成只描述耳朵；`Its ears are white.`，需改部位、顏色及單複數動詞，不能照抄 Before。 |
| `pet-looks-try-3` | 兔子的耳朵棕色；只把 `Its ears is brown.` 的 is 改成 are。 |
| `pet-looks-say-1` | 描述小貓白毛：`Its fur is white.`；The kitten has white fur 亦可。 |
| `pet-looks-say-2` | 同時描述小蜥蜴的尺寸與顏色：`The lizard is small and green.`，交換形容詞順序可接受，不可只答一個特徵。 |
| `pet-looks-say-3` | 狗的身體棕、腳白；只描述腳：`Its feet are white.`，The dog has white feet 亦可。 |

### `talking-about`：What are they talking about?

目標是從兩句短對話辨認主題，用現在進行式說明正在談論什麼，並按當下說話人數使用 he／she／they 與 is／are。口說 cue 只提供主詞；一個主題名詞不算完整回答。

| 題目 | 內容／答案與判準 |
| --- | --- |
| `talking-about-try-1` | Mia 談 hamster、Leo 談 rabbit；共同主題是 pets：`They are talking about pets.`。 |
| `talking-about-try-2` | 現在只剩 Mia 談自己的兔子；`She is talking about her rabbit.`，需改主詞、動詞及限定主題。 |
| `talking-about-try-3` | Sam 與 Kim 都在談金魚；只把 `They is talking about goldfish.` 的 is 改成 are。 |
| `talking-about-say-1` | Lily 談 hamster、Max 談 parrot；`They are talking about pets.`，their pets 或兩人名字作主詞皆可。 |
| `talking-about-say-2` | 只有 Ben 說自己的 kitten；`He is talking about his kitten.`，縮寫或 Ben 作主詞皆可。 |
| `talking-about-say-3` | 兩人分別談綠鳥與藍鳥；`They are talking about birds.`，their birds 可接受；不能只回答 green／blue。 |

### `same-color`：The same color

目標是用 like 將兩個卡片中同色的東西組成完整比較句。所有衣物均是假扮故事中的物件；不以孩子當天衣服或天空的實際顏色作答案。cue 保留主詞與 like，顏色與動詞仍須由卡片判讀。

| 題目 | 內容／答案與判準 |
| --- | --- |
| `same-color-try-1` | 藍襯衫與藍天空：`My shirt is blue like the sky.`。 |
| `same-color-try-2` | 同一情境改成一雙藍鞋；`My shoes are blue like the sky.`，需改單複數動詞，不能只換名詞仍留 is。 |
| `same-color-try-3` | 綠帽子與綠草；只把 `My hat are green like the grass.` 的 are 改成 is。 |
| `same-color-say-1` | 綠水瓶與綠草；`My bottle is green like the grass.`，just like 等自然變體可接受。 |
| `same-color-say-2` | 黃鞋子與卡片中的黃太陽；`My shoes are yellow like the sun.`，主詞複數及動詞需一致。 |
| `same-color-say-3` | 白襯衫與白雲；`My shirt is white like the clouds.`，The shirt 作主詞亦可。 |

兩題排列另接受 `My shirt is like the blue sky.` 與插入比較語的 `My shirt, like the sky, is blue.` 對應字序；鞋子版本相同，避免把符合卡片的自然排列誤判為錯。顏色、比較對象及主詞仍需全部正確。音訊示範固定使用最短標準答案。
