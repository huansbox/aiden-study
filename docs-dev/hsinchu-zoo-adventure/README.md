# 新竹動物園小小探險

> 使用日期：2026-08-14<br>
> 對象：一位成人帶 5.5 歲兒童<br>
> 目標：讓孩子帶路、觀察與做選擇；不以走完全園或解完卡片為目標
> 狀態：已完成並由使用者確認 PDF（2026-08-14）；本目錄作為可重印的歷史素材包，不列入平台執行中計畫。

- 卡面尺寸沿用 `animal-fight` 最新實作：`117 × 170 mm`。
- 適用標示 `122 × 175 mm` 的大 Poker；名義上四邊各留 `2.5 mm` 貼合容錯。
- 所有三選一題目都使用 `1／2／3`，不使用英文字母。

| 龜殼空拍員 | 可愛動物區龜類 | 從正上方比較外形、盾片與殼緣 | 只有側面時只指出一條殼線，不勉強選 |
| 狐獴挖土工具 | 狐獴展區 | 先看四趾長爪參考圖，再做交叉線索配對 | 卡片本身即可完成，現場前腳只是加碼 |
| 誰是昆蟲？ | 台灣昆蟲館支線 | 從獨角仙、蜘蛛、蜈蚣中判斷誰是昆蟲，並說一個理由 | 卡片本身可完成；不用把三隻全部解釋完 |
| 火車地圖小隊長 | 鶯歌至新竹車程 | 沿縣市邊界與鐵道，依數字找鶯歌、桃園、中壢、楊梅、湖口、新竹 | 找到任何一站就成功，不考比例或背誦 |
| 今天的最佳發現 | 回程／離園後 | 從「特別的地方、動作、喜歡」選一種，留下孩子最想記住的發現 | 只說、只指、畫一筆或不留下紀錄都成立 |

所有任務卡都沒有完成順序，也不需要依序拿出；火車地圖上的 `1–6` 僅表示列車經過站序。三選卡面一律使用 `1／2／3`。每張卡只玩一小段、跳過、收起或中途離園都成立。

## 現場用法

1. 火車上先拿「火車地圖小隊長」；抵達後把「地圖小隊長」放最前面，「誰是昆蟲？」放最後，其餘卡順序任意。
2. 火車每到一站，只請孩子找下一個數字，不要求記住六站。從新竹車站步行抵達一號入口後，再把園區地圖交給孩子；成人只說明目前位置。
3. 每到岔路，只問「你想往哪個圖案？」；不提醒還有幾張沒玩。
4. 到展區後才拿出對應卡。孩子沒興趣、動物沒出現或天氣太熱，就直接收起。
5. 回程再拿「今天的最佳發現」；只請孩子選一個，不核對卡片數量，也不追問「還有呢？」。

建議動線是從一號入口進園，先在可愛動物區與猛獸區之間讓孩子選擇，再往猴島、河馬與二號入口移動。這是少回頭的參考，不是必走順序。昆蟲館位於園外、靠一號入口方向；若要加碼，可回到一號入口離園時再決定。

## 列印與貼卡

1. 使用 A4 二分標籤紙，印表機選「A4 橫式」。
2. 縮放必須選 `100%`、`Actual size` 或「實際大小」，不要選「符合頁面」。
3. 單面列印，共 5 頁、每頁 2 張。
4. 先抽印第 1 頁，確認外框實測為 `117 × 170 mm`。
5. 沿外框裁切，貼在大 Poker 正面；四周預留約 `2.5 mm`。
6. 卡片下緣的「爸爸密語」故意倒放；需要答案時把卡旋轉 180 度即可。
7. 每張卡右下角都有清楚但不搶題目的日期 `2026-8-14`，作為日後回看時的行程記號。

- HTML 的圖資由原始 PNG 轉為 `q=100`、`alpha_q=100` 的 WebP；轉檔後已重新輸出與逐頁核對，列印版面與核可版一致。
- 經驗與設計原則放在可搜尋的 Markdown；單次行程細節與成品留在本目錄，避免把 repo 專案狀態寫進通用知識筆記。

## 內容依據與限制

- [新竹市立動物園開放時間](https://zoo-info.hccg.gov.tw/visit/opentime/)：週二至週日 09:00–17:00，動物展示至 16:40。
- [官方園區地圖](https://zoo-info.hccg.gov.tw/visit/map/)：簡化地圖依官方五大展示區與兩個入口重繪；不是精密比例圖，現場仍以路牌為準。
- [2026 年 7 月園區近況](https://zoo-info.hccg.gov.tw/%E6%96%B0%E7%AB%B9%E5%B8%82%E7%AB%8B%E5%8B%95%E7%89%A9%E5%9C%9290%E9%80%B1%E5%B9%B4%E3%80%8Czoo-my-way%E3%80%8D%E7%B3%BB%E5%88%97%E6%B4%BB%E5%8B%95%E9%96%8B%E8%B7%91%EF%BC%81%E9%AB%98%E8%99%B9/)：近期確認狐獴寶寶、新龜類與展區優化。
- [河馬介紹](https://zoo-info.hccg.gov.tw/portfolio-item/hippopotamus/)：眼睛、耳朵與鼻孔位於頭頂附近，方便泡水時觀察與呼吸。
- [紅毛猩猩](https://zoo-info.hccg.gov.tw/portfolio-item/bornean-orangutan/)與[灰長臂猿](https://zoo-info.hccg.gov.tw/portfolio-item/bornean-gibbon/)：猿類沒有尾巴，手臂適合攀爬與擺盪。
- [長鼻浣熊](https://zoo-info.hccg.gov.tw/portfolio-item/south-american-coati/)：主要線索是瘦長、可活動的鼻子與帶環紋的長尾。
- [台灣昆蟲館新竹館](https://taiwan.insect.tw/web/visit/visit.jsp?dm_no=DM1601346388304)：暑假週二至週日 10:00–17:00，一般參觀免費。
- [g0v 臺灣縣市界線 GeoJSON](https://github.com/g0v/twgeojson)：火車地圖的新北市、桃園市、新竹縣與新竹市外框由公開縣市界線資料簡化；站點名稱與順序依本次車次畫面。

動物可能因高溫、休息、醫療照護或自由躲藏而看不到。卡片刻意把「找到動物本人」以外的線索也算成功。
