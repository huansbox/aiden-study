# 115 四上自然後半冊範圍核對

2026-11-06 依康軒 **115 學年度完整課程計畫**核定本輪教材範圍為 U3「有趣的聲光現象」與 U4「好玩的電路」。這是整理歷屆題的教材範圍，**不是桃子腳正式期末考試範圍**；校方正式範圍仍未取得。來源與品質 backlog 沿用 [#178](https://github.com/huansbox/aiden-study/issues/178)，整合與後續交付由 [#249](https://github.com/huansbox/aiden-study/issues/249) 追蹤。

- 康軒[官方課程計畫入口](https://www.knsh.com.tw/service/plan)直接連到[國小新綱版公開資料夾](https://drive.google.com/drive/folders/1VjGyNCHi1Ilg9kqqgh-RhO9odaaS4Q8M)。沿「01橫式／01.上學期／4年級」，取得[橫式115(一)小自4上課程計畫.docx](https://drive.google.com/file/d/1cC6Aq6HL6F3deUEYTArgxFtHrbr0zNPQ/view)。文件開頭明載115學年度第一學期、四年級、康軒；完整架構依序為地表、水生環境、聲光、電路，後半冊活動及教學內容均可定位。它是出版者提供的校用空白範本，不能當成桃子腳已採用的週進度表。
- 康軒出版者在 [115 四上測驗卷公開商品目錄](https://www.pubu.com.tw/ebook/686991)亦列相同四單元，出版日期2026-09-01；僅使用公開目錄，未購買或下載受限電子書。
- 康軒[上學期期末數位服務](https://digitalmaster.knsh.com.tw/el/nature/digital1-final/)目前題名仍是114，僅作舊版交叉核對；其中折射明標延伸概念，不能拿此頁冒稱115完整教材或正式考試範圍。
