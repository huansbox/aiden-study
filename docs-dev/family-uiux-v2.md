# 家庭首頁與家長後台改版

2026-09-15 首次發布；2026-09-16 整合首頁卡片（#61）。沿用 `https://kids.linshuhuan.com/` 與現有家庭同步服務。

## 使用方式

孩子沿用 `/?child=aiden` 與 `/?child=bingpu`，頭像旁分別顯示「煦誠」與「秉樸」，家長後台的孩子選擇也使用同一份名稱。首頁採已確認的 D 大字海報方向，卡片採柔和灰藍等配色，預設 LEGO 人偶頭像。孩子頁沒有換人與家長入口；未指定孩子的根網址保留入口選擇。

家長直接開 `/parent/`，首次以家庭金鑰連接後由入口記住；詳見 [入口連線](device-connection.md)。可以選孩子、切換 LEGO／扁平頭像、開關與排序活動、隱藏題庫學期、安排週表或指定日期，最後按「儲存全部設定」。手機與電腦都能操作；孩子回首頁連線後取得更新。舊 `?view=parent` 會導向新後台。

單日安排取代當天週表。空的單日安排表示休息；「恢復週表」移除單日覆蓋。未完成任務不移到隔天。停用 App 或隱藏學期會暫停派發相關任務，但不刪原安排、題目或 App 進度。哥哥預設只顯示四上；弟弟之後可從後台開啟三下題庫。

任務完成依實際完成量，不要求全對。題庫／拼字以作答計數，注音包含教學卡和判分卡，長除法完成一整題才計數，數織看答案不計過關。任務達標會出現完成提示，可回首頁或繼續自由練習。拼字新增孩子自行聽音、輸入、判分的入口；原本家長預演與維護工具保留於維護模式。

## 首頁卡片與常用內容（#61）

- 每項活動只有一張卡。練習安排為選填；沒有安排時直接點卡片練習，有安排時卡內顯示內容、進度與完成狀態，另可選「自由練習」。空白單日安排覆蓋週表，活動仍可使用。
- 題庫按開放學期拆成科目卡。四上目前只有數學；三下才有社會、自然、國語。從科目卡進入後保持該科目，其他裝置同步進度也不會切走目前科目；既有進度不刪除。
- 「目前心智圖」：選孩子後，可勾選顯示、修改文章名稱與網址。煦誠預設〈悠閒午後〉；換週時替換即可，不保留孩子可見的舊文章清單。新文章內容先依 `learning-tasks/README.md` 製作，之後在這裡換入口。站內路徑如 `/leisure-mind-map/` 從平台部署位置解析；站內文章會回到原孩子首頁。
- 「常用網站」：共用清單，逐項填名稱、完整 HTTPS 網址、顯示孩子；可新增、編輯、移除。預設提供兩個孩子的「國字筆順」。外站另開視窗，不傳家庭參數，也不計入作答或時間。
- 「首頁排序」：先選孩子，再用上下箭頭移動卡片。心智圖、各科、app、常用網站都在同一份順序內。最後按「儲存全部設定」。
- 新版沿用同一網址與主畫面圖示，既有入口重新開啟連線後套用；不必重裝圖示。

家庭設定仍為 version 1，新增 `websites`、每個孩子的 `mindMap` 與 `homeOrder`。未曾設定的欄位讀取時補預設值；明確空網站清單或停用不會被補回。Worker 只在舊客戶端未送新增欄位時沿用雲端值，避免舊後台清掉新設定。題庫科目卡共用 study 的原有進度與累計，不另建科目存檔。

## 累計與成就

- 今日和累計的作答題數、練習分鐘；細表另列閱讀卡片。
- 只有正在練習且頁面在前景才計時，超過兩分鐘未操作停止累計；切到背景或離開練習停止計時。分鐘為估計值，不代表學會程度。
- 新紀錄不虛構舊時數。各 App 的既有錯題、熟練度與過關紀錄保留，和新累計分開。
- 10／50／100／250／500 題、1／5／20 個任務解鎖永久積木徽章；無兄弟排名、連續天數清零或按時間給獎勵。

## 資料與同步

`registry.json` 仍定義可提供的 App；家庭設定定義每個孩子實際看到的活動與順序。`family-core.js` 共用驗證、台灣日期、安排與累計規則；`family-client.js` 負責快取、計時與補送。

Worker 新增以下路由，全部經既有 family token 驗證：

| 路由 | 用途 | KV key |
| --- | --- | --- |
| `GET /v1/settings` | 讀家庭設定 | `c:family:settings` |
| `PUT /v1/settings` | 帶 rev、writeId 儲存；同 writeId 重送不重複更新 | 同上 |
| `GET /v1/activity/:child?cursor=…` | 分頁讀取累計串流，每頁最多 200 筆 | `m:<child>:…` |
| `PUT/POST /v1/activity/:child/:app/:device` | 合併同串流的累計快照 | `m:<child>:<app>:<device>` |

`device` 在這個新 API 代表單次開啟的寫入串流 ID；每次開啟獨立 UUID，避免同一瀏覽器兩個分頁互蓋增量。同一串流以各欄最大值合併；不同串流相加。完成任務是 occurrence 集合，不重複計次。本機保留未送出的快照；回首頁也會補送，不必重新進入原 App。背景使用 `text/plain` beacon，和 fetch 重送共用去重規則。

每次開啟會多一份小紀錄，長期資料量會增加；採分頁讀取，避免累計量增加後超過單次 Worker 的 KV 操作上限。依據：[Cloudflare KV 限制](https://developers.cloudflare.com/kv/platform/limits/)、[KV 分頁](https://developers.cloudflare.com/kv/api/list-keys/)。目前維持家庭規模的簡單方案，未新增資料庫或付費服務。

沿用 KV 最終一致的既有限制：跨裝置可能稍後才看見設定與紀錄；rev 檢查不等於原子鎖，同時修改設定仍可能後寫覆蓋。家長後台與孩子共用家庭權限，獨立頁面不是安全隔離的家長帳號。

數織原有過關資料仍只保存在裝置，但現在依孩子分開；哥哥可承接原本舊存檔，弟弟不承接。新累計紀錄照樣同步。
