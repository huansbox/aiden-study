# 作品登錄一次，產生 README 與家長白板

Status: accepted

2026-09-18，任務庫已累積 App、旅行卡、課後素材與主線外作品，手填總覽無法可靠反映來源；家長要求精簡白板且避免維護兩份清單。決定沿用 App registry，將 task 資料集中於 `learning-tasks/catalog.json`，由同一產生器輸出 README 索引與白板資料；同系列只在呈現上合併，不合併來源或狀態。

這取代 ADR-0007「手動維護 Markdown 任務索引」的做法，不改 task／app／shared 分類、任務資料夾規格或私用檔案界線。代價是多了結構化資料與產生／檢查步驟；選它是為了讓之後的 agent 只改一份來源，並由檢查抓漏登，而非靠每次記得更新兩個頁面。工作狀態仍須明確登錄；Git 只提供來源變更日期，不推論完成與否。
