| 順序 | 待補項目 | 完成訊號 |

| 1 | 補記環境 | 確認本次是 Safari 或主畫面 App、是否為孩子平常使用的容器；型號與 iPadOS 版本能取得時補記，不能取得則明載未知 |

| 3 | 補齊離開路徑 | 先記錄本次已測哪條路徑，再補回 hub、切背景、關閉重開中未涵蓋者；同容器已提交進度與剩餘批次保留、未提交輸入清空 |
| 4 | 備份、缺包與另一容器還原 | 家長確認匯出不含題文；在另一測試容器先還原進度、尚未取得題包時有明確提示，再自動取得相同題包後恢復進度可見；不覆蓋孩子目前有效進度 |
| 5 | 失敗時的快取與提示 | 服務／網路取題失敗時保留有效 cache 與 state；本機不能保存時有可理解提示。既有 desktop 503 證據保留，但真 iPad 尚未回報；頁面已開著時斷網不等於完整離線冷啟動通過 |

每項補驗記錄日期、環境、步驟與結果；不保存 token、題文、答案或孩子完整進度。不能安全重現的失敗情境先保留待驗，由統籌準備隔離的驗證方式，不對正式 Worker 製造故障或清除孩子的網站資料。
