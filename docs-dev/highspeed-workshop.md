# 700T／N700S 車鼻零件工坊

對應 [#217](https://github.com/huansbox/aiden-study/issues/217)。兩款都沿用已登錄 LEGO style PNG 與原始 part ID，車鼻特寫只是觀察玩具零件的組合；不表示真車機鼻可以展開。

## 特色操作

- **700T**：第 7 包的白色底、橘色中層、白色上層，依原分件上下接合。三件都已保存後，可點「分層」或上下拖動特寫，比較層次；第 12 包的 `p12-2` 檢修蓋與 `p7-1` 都已接上後，可點「試拆」或向左拖出蓋子，點「接回」或向右拖回。
- **N700S**：第 7 包依原分件接上長鼻底座、中央低稜、雙翼。三件都已保存後，可點「展開」或向上拖動特寫，雙翼向兩側分開，露出中央。`p7-3` 的左右圖像沿原 PNG 的自然分件縫裁切，仍是一組原始零件，沒有額外計包或零件進度。
- 滑桿與 SVG 操作區支援鍵盤方向鍵、Home／End；共用工坊處理選取、拖曳取消、Escape、回看、暫停與關閉。`endTrial()` 收回全部觀察位移，module 沒有計時器、storage 或 collection 寫入。
- 特寫只畫已保存的車鼻部件與前底盤，不補上尚未拼裝的車身。既有任意順序半成品直接由保存的 ID 還原；未完成所需零件時不出現對應操作區。

## 整合與驗證

`docs/shared/highspeed-mechanism.js` 提供 `KidsHighspeedMechanism.create(model)`，由 `train-workshop.js` 統一管理操作與保存；樣式在同名 CSS。`sourcesFor(ids)` 只要求目前已裝好的特寫 PNG，不會讓未來第 12 包的圖片阻擋第 7 包。

本機隔離入口為 `docs/parent/train-preview.html`，選 700T 或 N700S；此頁使用記憶體示範收藏，不讀寫孩子的正式進度。到第 7 包或第 12 包會自動切到特寫，也可用「特寫／全車」按鈕切換。

```sh
node --test tests/test_highspeed_workshop.mjs
```

測試涵蓋 v1／v2、原始 36／33 組各保存一次、任意順序半成品、取消與失敗重試、零包、圖片失敗、試玩不寫進度、未完成零件鎖定、未來圖片不阻擋、PNG 來源與動態可及性值。實際 browser 的點按、拖曳、鍵盤、窄版與 Pad 版面由整合驗收紀錄提供；沒有實體 iPad 或孩子長期使用驗收的主張。
