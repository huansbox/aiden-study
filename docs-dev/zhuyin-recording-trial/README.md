# 注音親錄：試錄與接續錄音

操作為「開始 → 說話 → 停止」。停止後自動存檔，再顯示下一個提示。先用 ㄅ、ㄇ、ㄚ 試錄；2026-09-17 使用者試過 AirPods 與 MBP 後，選擇 MBP 並授權接著錄剩下 11 段。全部完成後請家長回對話說「錄好了」，由 agent 讀取本機音檔檢查，不要求逐段下載、改名或搬檔。

在 Mac repo 根目錄啟動：

```sh
uv run python scripts/zhuyin_recording_trial.py

# 接續完整清單：沿用已錄三段，自動前往第一個尚未錄好的音
uv run python scripts/zhuyin_recording_trial.py --scope all
```

Safari 開啟 `http://127.0.0.1:8767/`。第一次需允許麥克風。這個網址只能在啟動工具的 Mac 使用，不是 iPad 或其他電腦的網址；本次不部署正式站。

- 錄音保存到 `~/Downloads/aiden-zhuyin-recording-trial/`，每次獨立資料夾，保留原始錄音、轉成 AAC 的 `audio.m4a` 與 `take.json`。不進 Git、不覆寫前一遍。
- 頁面重新開啟會找回已保存的片段；保存失敗時留住記憶體內錄音並顯示「重試保存」，不冒稱保存成功。
- 可選麥克風，清單會優先選 MacBook／內建裝置；選定後用 exact deviceId 開啟，裝置失效就提示重選，不默默改用 AirPods。錄音畫面與 `take.json` 保留瀏覽器實際回報的裝置名稱。
- 「再錄一輪全部音檔」會重新錄目前清單，舊檔全部保留；同一分頁重新整理會恢復本輪進度。`/?new=macbook` 可直接開新一輪，之後會移除該 query，避免重新整理再開一輪。接續剩餘 11 段時不要帶 `new`。
- 支援瀏覽器輸出的 MP4／WebM／Ogg，伺服器以 ffmpeg 轉為 mono 44100 Hz AAC。此階段不裁切、不做音量正規化、不宣稱發音或靜音檢查通過。
- 僅服務本機目前清單的錄音 key（預設試錄三段，`--scope all` 為 content.json 的全部 14 段），最長 30 秒、自動關閉麥克風。停止即存到此 Mac，沒有傳到雲端；不修改正式音檔、設定或學習進度。
- 可用 `--port` 與 `--output` 指定測試用連接埠與暫存目錄，讓自動測試的假麥克風音與家長錄音分開。

這是 #20 的錄音輔助工具，不是一次性家庭學習 task。完整清單由 content.json 展開，音節附漢字讀音與聲調提示，詞語則直接自然唸一次。錄音保存不等同已完成發音確認或正式入庫。
