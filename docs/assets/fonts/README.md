# 心智圖使用的字型

- 字型：字嗨注音黑體 Bold（BpmfZihiSans-Bold.ttf）。
- 來源：https://github.com/ButTaiwan/bpmfvs/releases/tag/v1.500
- 官方原始套件：https://github.com/ButTaiwan/bpmfvs/releases/download/v1.500/BpmfZihiSans.zip
- 字型檔保持原樣，未改造、裁字或轉檔，約 5.34 MB。
- 字型依 SIL Open Font License 1.1 內嵌與散布；原始 LICENSE-ZihiSans.txt、NOTICE.txt、LICENSE-2.0.txt 一併保留。
- 網頁直接載入本地字型，iPad 不需安裝系統字型；首次載入需下載字型檔，失敗時退回系統字型並顯示提示。

多音字的選擇符號只加在顯示文字，不改選項、存檔或抄寫字數。讀音序號依官方同版本表：
https://github.com/ButTaiwan/bpmfvs/blob/master/phonetic/versions/phonic_table_v1.500.txt

本文校正：長大（ㄓㄤˇ）、典當（ㄉㄤˋ）、巨著（ㄓㄨˋ）、覺得／辦得（˙ㄉㄜ）、妻子／兒子（˙ㄗ）、名字（˙ㄗ）、剛正不阿（ㄜ）。喪事（ㄙㄤ）、為官（ㄨㄟˊ）、當戶（ㄉㄤ）、轉分明（ㄓㄨㄢˇ）使用官方預設讀音。
