`selected-variants.png` 是使用者最後指定的原始四格圖，保留確切扁平角色設計。四個方形圖示由內建 image_gen 依選定圖抽取／延展背景，沒有加入原始孩子照片。圖示為生成式重整，原始四格圖保留作為造型參考。

生成 prompt 組：以四格圖為 edit target，每次只抽取一個角色；移除其他角色、標題、米色邊框，延展藍色／黃色背景至方形四角、不預先加圓角；保留完整頭髮、表情、服裝與臉部比例。LEGO 取下排：哥哥張嘴笑、白衣；弟弟閉嘴笑、紅衣白領。扁平版取使用者最後指定圖上排：保留較寫實的插畫眼睛、短刺髮細節與臉部陰影，不簡化成幾何向量角色或 LEGO。

使用內建 image_gen，未使用 CLI fallback。方形圖由頁面和 iPad 自行套用圓角。
